<a id="current-failures"></a>

## 当前故障

打开**工作流程运行→需要注意**。与历史失败的运行不同，此队列保留最新完成的运行失败的可操作工作流上下文。较新的成功运行、关闭的相关更改或合并的更改会在同步后删除上下文。较旧的分支范围运行可以与启动时活动的拉取/合并请求相关联。侧边栏徽章使用相同的权限范围队列。

搜索并使用可用的表格控件来缩小工作流程/存储库上下文的范围。打开其外部运行链接以获取日志和修复。打开相关更改（如果存在）。 Repovio 从不重新运行、取消、编辑或分派工作流程。

<a id="diagnose-missing-or-stale-entries"></a>

## 诊断丢失或过时的条目

成功替换运行后，空结果可能是正确的。对于较旧的故障，请使用
[所有运行](/docs/v2.0/workflow-runs)。在将不存在的上下文视为丢失数据之前，请清除过滤器并检查存储库成员资格。提供者操作是异步观察的；检查
[同步任务](/docs/v2.0/guide-jobs) 状态是否保持陈旧。加载和请求错误与空队列是分开的； API 恢复后重试。
