<a id="review-accounts"></a>

## اکاؤنٹس کا جائزہ لیں۔

سسٹم کے منتظمین **ایڈمنسٹریشن → صارفین** کھولتے ہیں۔ جدول صارف نام، اوتار/ڈسپلے کا نام، کردار، مقامی/OIDC اصل، اور تخلیق
شدہ/اپ ڈیٹ کردہ ٹائم سٹیمپ دکھاتا ہے۔ کردار کے لحاظ سے فلٹر کریں، ترتیب دیں، کالم تبدیل کریں، یا صفحہ بندی کریں۔ ناظر یا
مینیجر کے لیے مخزن تک رسائی کے لیے علیحدہ [مخزن کی رکنیت](/docs/v2.0/repositories) کی ضرورت ہوتی ہے۔ شناخت فراہم کرنے
والے گروپ وہ رکنیت نہیں بناتے ہیں۔

<a id="provisioning-and-deletion"></a>

## فراہمی اور حذف کرنا

انتظام → صارفین میں ٹول بار سے نیا صارف منتخب کریں۔ منفرد نام، اختیاری پہلا/آخری نام، 12–256 حروف کا پاس ورڈ اور تصدیق،
نیز کردار دیں؛ ابتدائی Viewer ہے۔ OIDC فعال ہو تب بھی اکاؤنٹ بن سکتا ہے۔ OIDC شناخت فراہم کنندہ سے آتی ہے، یکساں مقامی
نام سے منسلک نہیں ہوتی۔

ڈیلیٹ ایکشن دوسرے صارفین کے لیے دستیاب ہے اور فوری طور پر عمل میں لایا جاتا ہے۔ اکاؤنٹ کو منتخب کرنے سے پہلے اس کا جائزہ
لیں۔ آپ اس API یا اسکرین کے ذریعے اپنا اکاؤنٹ حذف نہیں کر سکتے۔ Repovio صارف کو حذف کرنے سے مقامی رسائی ختم ہوجاتی ہے۔
یہ GitHub، GitLab، Forgejo، یا Gitea پر کسی بھی فراہم کنندہ کے اکاؤنٹ کو حذف نہیں کرتا ہے۔ حذف کرنے سے پہلے متاثرہ صارف
کی رسائی کا جائزہ لیں۔

<a id="user-mcp-tokens"></a>

## صارف MCP ٹوکنز

ٹوکن میٹا ڈیٹا کی فہرست بنانے یا تصدیق کے ساتھ ٹوکن منسوخ کرنے کے لیے صارف کا MCP-ٹوکن ڈائیلاگ کھولیں۔ منتظمین اس
ڈائیلاگ کے ذریعے سادہ متن کے ٹوکن کی قدروں کو بازیافت نہیں کرسکتے ہیں یا کسی دوسرے صارف کا ٹوکن نہیں بنا سکتے ہیں۔
صارفین [MCP ترتیبات](/docs/v2.0/mcp) میں اپنے ٹوکن بناتے ہیں۔ خالی فہرستیں اور لوڈ کی غلطیاں الگ الگ ہیں۔ API ریکوری کے
بعد دوبارہ کوشش کریں۔ سپورٹ رپورٹس یا اسکرین شاٹس میں کبھی بھی ٹوکن ویلیو کاپی نہ کریں۔

<a id="local-user-api"></a>

## API کے ذریعے مقامی صارف فراہم کریں۔

ایڈمنسٹریٹر بیئرر تصدیق اور `Content-Type: application/json` کے ساتھ `POST /api/v1/users` بھیجنے کے لیے HTTPS پر API
کلائنٹ کا استعمال کریں۔ کلائنٹ کے محفوظ ان پٹس میں پلیس ہولڈرز کو تبدیل کرتے ہوئے اس درخواست کی باڈی فراہم کریں:

```json
{
  "username": "new-user",
  "password": "REPLACE_WITH_A_PASSWORD_OF_AT_LEAST_12_CHARACTERS",
  "role": "VIEWER"
}
```

درست کردار `VIEWER`، `MANAGER`، اور `SYSTEM_ADMIN` ہیں۔ صرف مطلوبہ کردار تفویض کریں، پھر مخزن کی رکنیت الگ سے دیں۔ جواب
میں محفوظ صارف میٹا ڈیٹا ہے، پاس ورڈ یا اس کا ہیش نہیں۔ دوبارہ کوشش کرنے سے پہلے ایک ڈپلیکیٹ صارف نام یا غلط درخواست کو
درست کرنا ضروری ہے۔ ٹریک شدہ فائلوں، شیل ہسٹری، اسکرین شاٹس، یا ایشو رپورٹس میں پاس ورڈز یا بیئرر ٹوکن اسٹور نہ کریں۔

<a id="create-and-reset-local-accounts"></a>

## مقامی اکاؤنٹس بنانا اور ری سیٹ کرنا

مقامی اکاؤنٹ کی قطار میں پاس ورڈ ری سیٹ سے منتظم پرانا جانے بغیر نیا پاس ورڈ دیتا ہے۔ نیا پاس ورڈ اور تصدیق درج کریں۔
پرانے JWT سیشن غیر مؤثر ہوتے ہیں؛ اپنا ری سیٹ آپ کو باہر کرتا ہے۔ OIDC اکاؤنٹ کے لیے یہ عمل نہیں۔ MCP ٹوکن منسوخ نہیں
ہوتے۔

<a id="local-access-groups"></a>

## مقامی رسائی گروپ

انتظام → صارف گروپ میں بنائیں، نام بدلیں، حذف کریں اور ارکان شامل یا نکالیں۔ نام منفرد اور غیر خالی ہوں۔ انتخاب میں تلاش
اور صفحات ہیں؛ صارف کئی گروپس میں ہو سکتا ہے، اندرونی گروپس نہیں۔ حذف کی تصدیق درکار ہے اور رکنیت و وراثتی حقوق ختم ہوتے
ہیں، براہ راست تعیناتیاں باقی رہتی ہیں۔

ریپوزٹری کے گروپ رسائی حصے میں Viewer یا Manager دیں، بدلیں یا ہٹائیں۔ براہ راست اور وراثتی حقوق ملتے ہیں؛ Manager غالب
ہے۔ انتظام کے لیے عالمی Manager کردار بھی چاہیے؛ سسٹم منتظم غیر محدود ہیں۔ دوسری اجازت نہ ہو تو اگلی درخواست پر منسوخی
مؤثر ہے۔ گروپس مقامی اور OIDC اکاؤنٹس لیتے ہیں، OIDC claims سے ہم وقت نہیں ہوتے۔

```text
POST   /api/v1/users                              { username, password, role, firstName?, lastName? }
PUT    /api/v1/users/:id/password                 { newPassword }
GET    /api/v1/user-groups                       ?page=1&perPage=10
POST   /api/v1/user-groups                       { name }
PUT    /api/v1/user-groups/:id                    { name }
DELETE /api/v1/user-groups/:id
GET    /api/v1/user-groups/:id/members            ?page=1&perPage=10
PUT    /api/v1/user-groups/:id/members/:userId
DELETE /api/v1/user-groups/:id/members/:userId
GET    /api/v1/repositories/:id/group-memberships
PUT    /api/v1/repositories/:id/group-memberships/:groupId  { role }
DELETE /api/v1/repositories/:id/group-memberships/:groupId
```
