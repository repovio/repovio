<a id="search-the-installation"></a>

## Поиск установки

Откройте поиск из панели приложения или используйте отображаемое сочетание клавиш. Введите не менее двух символов.
Результаты группируются по местам назначения навигации, репозиториям, учетным записям поставщиков и запускам рабочих
процессов. Для сопоставления навигации используются переведенные метки пунктов назначения, к которым может получить
доступ ваша учетная запись; результаты ресурсов используют синхронизированные имена поставщиков.

Перемещайтесь по результатам с помощью клавиатуры или выбирайте результат с помощью указателя. Сопоставления репозитория
и учетной записи поставщика открывают соответствующее представление Repovio; рабочий процесс соответствует открытому
URL-адресу запуска поставщика. Нажмите **Escape**, чтобы закрыть поиск и вернуться на предыдущую страницу. Поиск не
выполняет обнаружение на стороне поставщика и не запускает синхронизацию.

<a id="access-and-failure-states"></a>

## Состояния доступа и сбоя

Поиск ресурсов использует разрешения текущего пользователя на репозиторий. Результаты учетной записи поставщика доступны
только администраторам. Отсутствие результатов может означать короткий запрос, отсутствие соответствующих сохраненных
записей или недостаточное членство. Попробуйте указать более конкретное имя и проверьте репозиторий/задание, если
синхронизированные данные отсутствуют. Загрузка отображается во время выполнения запроса. В случае ошибки запроса
повторите запрос после восстановления подключения API. Поиск никогда не выявляет токены поставщика или учетные данные
уведомлений.
