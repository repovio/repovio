---
title: 'API রেফারেন্স'
description: 'এই Repovio রিলিজের জন্য শেষ পয়েন্ট, পরামিতি, অনুরোধ সংস্থা এবং প্রতিক্রিয়া স্কিমাগুলি অন্বেষণ করুন৷'
---

এই রিড-ওনলি রেফারেন্সটি নির্বাচিত অ্যাপ্লিকেশন রিলিজ থেকে তৈরি করা হয়েছে। একটি শেষ বিন্দু খুঁজে পেতে অনুসন্ধান ক্ষেত্র
ব্যবহার করুন; নেস্টেড ক্ষেত্রগুলির জন্য স্কিমার বিবরণ প্রসারিত করুন এবং প্রয়োজনে সম্পূর্ণ OpenAPI JSON ডাউনলোড করুন।

আপনার ইনস্টলেশন দ্বারা পরিবেশিত ডকুমেন্টেশনের জন্য, [API অ্যাক্সেস](/docs/v2.0/api-access) দেখুন।
