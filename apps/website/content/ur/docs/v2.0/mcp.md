Repovio `/mcp` پر ایک سٹیٹ لیس ماڈل سیاق و سباق پروٹوکول اینڈ پوائنٹ کو ظاہر کرتا ہے۔ یہ انہی ریپوزٹریوں، ورک فلو رن،
ناکامی کی قطاروں، منظوری کی قطاروں، خلاصوں اور رجحانات تک صرف پڑھنے کی رسائی فراہم کرتا ہے جو کہ تصدیق شدہ صارف Repovio
میں دیکھ سکتا ہے۔

MCP سرور مقامی Repovio ڈیٹا بیس کو پڑھتا ہے۔ یہ فراہم کنندہ کے اتپریورتن APIs کو کال نہیں کرتا، مطابقت پذیری شروع کرتا
ہے، ورک فلو کو منظور کرتا ہے، یا Repovio کنفیگریشن کو تبدیل نہیں کرتا ہے۔

<a id="create-an-access-token"></a>

## ایک رسائی ٹوکن بنائیں

**سیٹنگز** کھولیں،**MCP رسائی** ٹیب کو منتخب کریں، اور ایک نامزد ٹوکن بنائیں۔ میعاد ختم ہونا اختیاری ہے۔ تخلیق ڈائیلاگ
سے مکمل ٹوکن کاپی کریں کیونکہ Repovio اسے صرف ایک بار دکھاتا ہے اور صرف اس کی SHA-256 ہیش کو اسٹور کرتا ہے۔

ٹوکن کو منسوخ کرنا اگلی درخواست پر اثر انداز ہوتا ہے۔ اس کے صارف کو حذف کرنے سے ٹوکن بھی حذف ہوجاتا ہے۔ صارف کے کردار یا
ریپوزٹری ممبرشپ میں تبدیلیاں فوری طور پر لاگو ہوتی ہیں کیونکہ ہر درخواست ڈیٹا بیس سے موجودہ اجازت کو حل کرتی ہے۔

<a id="configure-a-client"></a>

## ایک کلائنٹ کو ترتیب دیں۔

عوامی Repovio اصل کا استعمال کریں اور اس کے بعد `/mcp` اور اجازت کے ہیڈر میں ٹوکن بھیجیں:

```text
URL: https://repovio.example.com/mcp
Authorization: Bearer repovio_mcp_REPLACE_WITH_TOKEN
```

پہلی ریلیز MCP کلائنٹس کو نشانہ بناتی ہے جو حسب ضرورت HTTP ہیڈر کو سپورٹ کرتے ہیں، جیسے ایڈیٹر اور کمانڈ لائن کلائنٹس۔
یہ OAuth دریافت فراہم نہیں کرتا ہے اور میزبانوں کے ساتھ مطابقت کا دعوی نہیں کرتا ہے جنہیں MCP OAuth بہاؤ کی ضرورت ہوتی
ہے۔

ٹوکن کو کبھی بھی URL، استفسار پیرامیٹر، ٹریک شدہ کنفیگریشن فائل، شیل ہسٹری، یا لاگ میں نہ رکھیں۔ کلائنٹ کے خفیہ اسٹوریج
یا غیر تبدیل شدہ ماحولیاتی متغیر کو ترجیح دیں۔

<a id="available-tools"></a>

## دستیاب ٹولز

| ٹول                      | مقصد                                                                           |
| ------------------------ | ------------------------------------------------------------------------------ |
| `list_repositories`      | نظر آنے والے ٹریک شدہ ذخیروں کی فہرست بنائیں۔                                  |
| `get_repository`         | ایک نظر آنے والا ٹریک شدہ ذخیرہ پڑھیں۔                                         |
| `list_workflow_runs`     | استفسار معمول کے مطابق مرئی ورک فلو چلتا ہے۔                                   |
| `list_needs_attention`   | ورک فلو کے سیاق و سباق کی فہرست بنائیں جن کا تازہ ترین ٹرمینل رن ناکام ہو گیا۔ |
| `list_awaiting_approval` | فراہم کنندہ کی منظوری کے منتظر موجودہ نظر آنے والے رنز کی فہرست بنائیں۔        |
| `get_dashboard_summary`  | ایک جامع وقت کی حد کے لیے مرئی ورک فلو کی صحت کا خلاصہ کریں۔                   |
| `get_workflow_trend`     | مجموعی طور پر نظر آنے والی کامیابی اور ناکامی کے رجحان کی بالٹیاں۔             |

فہرست ٹولز کو فی صفحہ 25 نتائج پر ڈیفالٹ کریں اور زیادہ سے زیادہ 100 کو قبول کریں۔ ٹول آؤٹ پٹ میں ساختہ JSON اور مماثل
متن کی نمائندگی ہوتی ہے۔ تاریخیں ISO 8601 UTC اقدار استعمال کرتی ہیں۔

سرور جان بوجھ کر MCP وسائل، اشارے، کاموں، سبسکرپشنز، فراہم کنندہ کے اعمال، یا کنفیگریشن ٹولز کی تشہیر نہیں کرتا ہے۔

<a id="reverse-proxy-requirements"></a>

## ریورس پراکسی کی ضروریات

- `POST /mcp` کو `/api/v1/mcp` پر دوبارہ لکھے بغیر API کنٹینر میں آگے بھیجیں۔
- `Authorization`، `Origin`، `Content-Type`، `Accept`، `MCP-Protocol-Version`، `Mcp-Method`، اور `Mcp-Name` کو آگے کریں۔
- ریورس پراکسی پر TLS استعمال کریں اور اجازت نامے کے ہیڈر کو لاگ نہ کریں یا استفسار کے تاروں کی درخواست نہ کریں۔
- ہر اجازت یافتہ براؤزر کی اصل کو `CORS_ORIGIN` میں شامل کریں۔ `Origin` ہیڈر کے بغیر درخواستیں مقامی کلائنٹس کے لیے
  معاون رہیں گی۔ موجودہ ماخذ کو کنفیگر کردہ اجازت کی فہرست سے مماثل ہونا چاہیے۔

<a id="token-administration"></a>

## ٹوکن انتظامیہ

صارفین سیٹنگز کے تحت **MCP رسائی** ٹیب میں اپنے ٹوکنز کا نظم کرتے ہیں۔ سسٹم ایڈمنسٹریٹر محفوظ ٹوکن میٹا ڈیٹا کا معائنہ
کر سکتے ہیں اور یوزرز پیج سے ٹوکن کو کالعدم کر سکتے ہیں، لیکن اس کے ہیش یا سادہ متن کے راز کو بازیافت نہیں کر سکتے اور
دوسرے صارف کی جانب سے ٹوکن نہیں بنا سکتے۔

<a id="manage-token-states"></a>

## ٹوکن ریاستوں کا نظم کریں۔

ٹوکن لسٹ نام، حیثیت، محفوظ سابقہ، تخلیق شدہ/آخری استعمال شدہ ٹائم اسٹیمپ، اور اختیاری میعاد کو ظاہر کرتی ہے۔ ناموں میں
زیادہ سے زیادہ 100 حروف ہوسکتے ہیں۔ منسوخی کی تصدیق کی ضرورت ہے۔ منسوخ یا ختم شدہ ٹوکن مستقبل کی درخواستوں کی تصدیق نہیں
کر سکتا۔ خالی فہرست کا مطلب ہے کہ صارف کے لیے کوئی ٹوکن موجود نہیں ہے۔ لوڈ کی غلطی دوبارہ کوشش کی پیشکش کرتی ہے۔ ایک بار
کے ڈسپلے کو بند کرنے سے پہلے مکمل نئے ٹوکن کو کاپی کریں۔ ایڈمنسٹریٹر ٹوکن ڈائیلاگ صرف فہرست سازی/منسوخ کی اجازت دیتے
ہیں، کسی دوسرے صارف کے لیے کبھی تخلیق نہیں کرتے۔
