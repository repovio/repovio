<a id="browse-and-open-details"></a>

## 浏览并打开详细信息

从表格打开仓库，即可在概览、工作流运行、议题、拉取请求、安全警报和设置之间切换。活动页面始终限定于当前仓库，
并提供筛选、排序、分页和行导航。查看安全警报需要管理权限；设置仅向系统管理员开放。提供商链接打开外部仓库。

概览显示基本信息、保留策略、上次同步、数据时效、间隔、当前任务和近期活动。等待或运行中的任务显示进度；
警告和错误提供经过安全处理的分类信息。

<a id="add-and-maintain-tracking"></a>

## 添加和维护跟踪

只有系统管理员才能添加存储库。选择一个已启用的提供商帐户，等待发现，然后选择一个或多个未跟踪的存储库。已跟踪的存储库被排除在外。如果多次添加的一部分失败，则成功的选择将保留添加，并且仅保留失败的选择以供重试。空的提供商列表需要首先连接启用的
[提供商帐户](/docs/next/provider-accounts)。

管理员可以启用/禁用跟踪、**刷新提供程序数据**以及对只读同步进行排队。存储库标识使用提供者帐户和稳定的提供者存储库 ID。重命名/转移保留历史记录、过滤器、会员资格和频道；元数据刷新拒绝旧路径上的不同 ID，而不是重新分配它。禁用的存储库保留存储的数据，但停止参与同步。

<a id="repository-settings-sections"></a>

## 仓库设置分区

仓库设置提供五个二级标签页。每个分区使用可用宽度，窄屏上的表单字段纵向排列。标签页链接可分享，并可通过重新加载或前进、后退恢复。默认选中“常规”。

| 分区           | 用途                     | 地址                         |
| -------------- | ------------------------ | ---------------------------- |
| 常规           | 覆盖保留期限             | `/repositories/:id/settings` |
| Webhook        | 仓库 Webhook 配置        | `?tab=webhook`               |
| 工作流筛选条件 | 允许和拒绝的工作流模式   | `?tab=workflow-filters`      |
| 成员           | 用户直接访问及仓库角色   | `?tab=members`               |
| 用户组访问权限 | 本地用户组的附加访问权限 | `?tab=groups`                |

在同一次设置访问中切换标签页会保留未保存的输入和待处理请求。离开设置或打开另一个仓库时会清除草稿，包括生成的 Webhook 密钥。请使用各分区的保存或分配操作保存修改，不要把切换标签页当作保存。

快速详情对话框已移除。旧的 `?repository=` 链接会打开概览。完整详情页保留刷新、同步、提供商链接和本地删除操作。查看者和管理者无法通过修改地址获得设置权限。

<a id="retention-filters-and-memberships"></a>

## 保留、过滤器和会员资格

管理员设置单独的工作流运行、问题和拉取请求保留覆盖，每个覆盖天数从 1 到 3650 天。空值恢复相应的
[系统默认](/docs/next/settings-system)。工作流过滤器接受 **ALLOW** 和**DENY**
全局模式；否认优先。添加非空模式或删除现有模式。限制性过滤器可以解释缺席的运行。

在成员资格中，将非管理员用户添加为查看者或管理员、更改其存储库角色或删除访问权限。管理员被排除在成员选择之外，因为他们已经拥有不受限制的访问权限。全局管理器仍然需要管理器成员资格才能获得存储库管理功能（例如安全警报）。

<a id="webhooks-and-failures"></a>

## Webhook 和失败

存储库 Webhook 卡显示回调 URL、配置状态、提供程序说明和上次交付。它可以生成/复制秘密、保存配置、通过显式确认轮换或删除配置。必须在提供商注册之前修复缺失的公共 URL。秘密仅在配置期间显示；将它们保存在秘密管理器中。按照
[存储库网络钩子](/docs/next/provider-webhooks) 进行设置和验证。

查看者和管理者可在概览中查看只读仓库元数据，设置仍仅供系统管理员使用。修复原因后再重试，并通过[任务](/docs/next/guide-jobs)检查同步故障。

<a id="local-user-and-group-management"></a>

## 本地访问组

在仓库的组访问区域分配 Viewer 或 Manager，修改或移除授权。直接与继承授权取并集，Manager 优先。管理仍需全局 Manager 角色，系统管理员不受限制。移除在下一请求生效，其他授权仍可保留访问。组支持本地和 OIDC 账户，不从 OIDC 声明同步。

[本地访问组](/docs/next/users#local-access-groups)

<a id="delete-local-tracking"></a>

## 删除本地跟踪

系统管理员可以在详情页中选择 **删除仓库**。确认信息会显示仓库名称，并说明将永久删除本地工作流、运行、Issue、Pull Request、安全警报、配置、访问授权、Webhook 历史、同步状态以及相关通知历史。提供商账户及提供商处的仓库数据保持不变。

同步运行期间禁止删除，请等待完成后重试。待处理的同步请求会随仓库一起删除。通知订阅会移除此仓库的筛选条件；如果订阅仅限于此仓库，则删除该订阅，而不会将其变为全局订阅。共享通知渠道仍会保留。

之后可以通过现有的提供商选择重新添加仓库。跟踪将从头开始，不恢复之前的本地历史或配置。
