<a id="edit-a-local-profile"></a>

## 编辑本地配置文件

打开**设置→常规**。本地用户可以更新可选的名字/姓氏及其登录用户名。使用个人姓名作为首选显示身份；用户名仍然可用于明确识别。字段的最大长度为 255 个字符，并且用户名不能为空。

更改用户名需要当前密码。在配置文件表单中输入它并选择保存。仅名称不需要更改用户名。等待请求；成功保存会更新当前帐户。重复的用户名和不正确的当前密码会产生不同的验证错误。更正受影响的字段并重试。

<a id="identity-managed-accounts"></a>

## 身份管理帐户

OIDC 用户无法在本地更改其用户名或配置文件名称。 Repovio 在成功登录时同步来自已验证身份声明的名称。在身份提供商处更改它们并重新登录。在
[头像设置](/docs/v1.0/avatar) 中，头像仍可单独编辑。如果profile请求失败，API恢复后重试；不要通过支持渠道提交密码。
