## Вкладки настроек

Откройте **Настройки** в меню пользователя. Каждый прошедший проверку подлинности пользователь может получить доступ к
разделам**Общие** и**MCP**. Системные администраторы также видят**Аутентификация** и**Система**. Группировка
администраторов на боковой панели не мешает другим вошедшим в систему пользователям открывать свои личные настройки
через меню пользователя.

Общие содержат [Профиль](/docs/v2.0/profile), [Аватар](/docs/v2.0/avatar) и для локальных учетных записей
[Пароль](/docs/v2.0/password). Пользователи, управляемые OIDC, видят уведомление об управлении идентификацией вместо
форм локального профиля и пароля, но по-прежнему могут редактировать свой аватар. [MCP](/docs/v2.0/mcp) управляет
личными токенами доступа только для чтения.

<a id="related-preferences"></a>

## Связанные настройки

[Язык](/docs/v2.0/language) и [Появление](/docs/v2.0/appearance) выбираются из элементов управления
приложения/пользователя. Администраторы настраивают [Аутентификация OIDC](/docs/v2.0/authentication) и
[Системные настройки по умолчанию](/docs/v2.0/settings-system) на соответствующих вкладках. Отсутствующая вкладка может
соответствовать вашей роли; изменение URL-адреса не дает авторизации. Повторяйте неудачные запросы настроек только после
проверки подключения API.
