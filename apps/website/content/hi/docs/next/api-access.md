## स्थापित एपीआई दस्तावेज़ीकरण

प्रत्येक Repovio API सर्वर `/docs` पर अपने इंटरैक्टिव API दस्तावेज़ प्रस्तुत करता है। स्थानीय विकास में,
`http://localhost:3001/docs` खोलें। REST समापन बिंदु `/api/v1` आधार पथ का उपयोग करते हैं।

परिनियोजन के लिए, बाहरी रूप से पहुंच योग्य एपीआई मूल और अपने रिवर्स प्रॉक्सी द्वारा कॉन्फ़िगर किए गए पथ का उपयोग करें।
उदाहरण के लिए, यदि एपीआई सर्वर `https://repovio.example.com` पर प्रदर्शित होता है, तो इसका दस्तावेज़ीकरण
`https://repovio.example.com/docs` पर प्रदर्शित किया जा सकता है। वेब एप्लिकेशन इस मार्ग को स्वचालित रूप से प्रॉक्सी नहीं
करता है; यदि आप अपने प्रॉक्सी को उजागर करना चाहते हैं तो उसे स्पष्ट रूप से कॉन्फ़िगर करें। `/api/v1/docs` दस्तावेज़ीकरण
मार्ग नहीं है.

स्थापित संदर्भ चल रहे एप्लिकेशन का वर्णन करता है। उस इंटरैक्टिव संदर्भ से किए गए अनुरोध आपके उदाहरण का उपयोग करते हैं और
प्रत्येक ऑपरेशन के लिए प्रमाणीकरण और अनुमतियों की आवश्यकता होती है। साइन-इन और खाता कॉन्फ़िगरेशन के लिए
[प्रमाणीकरण](/docs/next/authentication) देखें। MCP एक्सेस टोकन [MCP ग्राहक](/docs/next/mcp) के लिए हैं, सामान्य REST
बियरर टोकन के रूप में नहीं।

## स्टेटिक रिलीज संदर्भ

इस वेबसाइट पर [एपीआई संदर्भ](/docs/next/api-reference) चयनित रिलीज़ के सटीक एप्लिकेशन संशोधन से उत्पन्न केवल पढ़ने योग्य
स्नैपशॉट है। इसे चलने वाले Repovio इंस्टेंस की आवश्यकता नहीं है और यह API अनुरोध नहीं भेजता है। अपनी स्थापना से मेल खाने
वाला संस्करण चुनें; स्थापित `/docs` पेज आपके रनिंग बिल्ड के लिए आधिकारिक बना हुआ है।

विधि, पथ या विवरण के आधार पर खोजें, पैरामीटर और प्रतिक्रिया स्कीमा का निरीक्षण करें, या संदर्भ पृष्ठ से संपूर्ण OpenAPI
JSON डाउनलोड करें। स्कीमा पहचानकर्ता और एपीआई विवरण जेनरेट किए गए अनुबंध की भाषा को बनाए रखते हैं।
