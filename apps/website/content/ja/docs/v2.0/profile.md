## ローカルプロファイルを編集する

**[設定] → [一般]**
を開きます。ローカル ユーザーは、オプションの姓名とログイン ユーザー名を更新できます。個人名は優先表示 ID として使用されます。ユーザー名は、明確な識別のために利用可能なままです。フィールドの最大長は 255 文字であり、ユーザー名を空にすることはできません。

ユーザー名を変更するには、現在のパスワードが必要です。プロフィールフォームに入力し、保存を選択します。名前だけを変更する必要はありません。リクエストを待ちます。保存に成功すると、現在のアカウントが更新されます。ユーザー名が重複していたり​​、現在のパスワードが間違っていたりすると、さまざまな検証エラーが発生します。影響を受けるフィールドを修正して、再試行してください。

<a id="identity-managed-accounts"></a>

## ID 管理アカウント

OIDC ユーザーは、ユーザー名またはプロファイル名をローカルで変更できません。 Repovio は、ログイン成功時に検証済みの ID クレームからの名前を同期します。 ID プロバイダーでそれらを変更し、再度サインインします。アバターは、[アバター設定](/docs/v2.0/avatar)
で個別に編集可能なままです。プロファイルリクエストが失敗した場合は、API リカバリ後に再試行してください。サポート チャネルを通じてパスワードを送信しないでください。
