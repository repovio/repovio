> محفوظ شدہ ماخذ سنیپ شاٹ۔ پروڈکٹ لیبلز Repovio استعمال کرتے ہیں۔ اس ریلیز کی ٹیگ شدہ تعیناتی فائلوں سے کنفیگریشن شناخت
> کنندگان اور کنٹینر حوالہ جات کو بغیر تبدیلی کے استعمال کریں۔

<a id="access-and-channel-list"></a>

## رسائی اور چینل کی فہرست

**آپریشنز → اطلاعات → چینلز** کھولیں۔ چینلز عالمی Repovio کنفیگریشن ہیں، نہ کہ ریپوزٹری کی ملکیت والے مینیجر کنفیگریشن۔
سسٹم ایڈمنسٹریٹر چینلز تخلیق، ترمیم، جانچ، فعال/غیر فعال، اور حذف کرتے ہیں۔ ریپوزٹری مینیجر کی حیثیت چینل کی انتظامیہ کی
اجازت نہیں دیتی ہے۔ ٹیبل نام، قسم، محفوظ منزل کا میٹا ڈیٹا، سبسکرائب شدہ واقعات، فعال حالت، اور اپ ڈیٹ شدہ وقت دکھاتا
ہے۔ قسم/فعال فلٹرز، چھانٹی، کالم کنٹرول، اور صفحہ بندی کا استعمال کریں۔

<a id="create-a-destination"></a>

## ایک منزل بنائیں

**چینل شامل کریں** کا انتخاب کریں، ایک نام درج کریں، ایک قسم منتخب کریں، اور منزل کو ترتیب دیں:

- **ای میل:** SMTP میزبان/پورٹ، ٹرانسپورٹ سیکیورٹی، بھیجنے والا، اختیاری تصدیق، اور وصول کنندگان۔
- **Gotify:** سرور URL، ایپلیکیشن ٹوکن، اور ترجیح۔
- **ntfy:** سرور، موضوع، اختیاری تصدیق/ٹوکن، اور ترجیح۔
- **Discord:** ویب ہک کی منزل۔
- **حسب ضرورت Apprise URL:** ایک تعاون یافتہ Apprise سروس URL۔
- **براؤزر پش:** وصول کنندہ صارفین؛ ہر وصول کنندہ کو [ان کا آلہ](/docs/v1.0/browser-push) کو فعال کرنا ہوگا۔

اسی ڈائیلاگ میں [ایونٹ کی رکنیت اور پیش نظارہ](/docs/v1.0/notification-rules) کو کنفیگر کریں۔ محفوظ کریں اور بند کرنے سے
پہلے درخواست کا انتظار کریں۔ توثیق یا محفوظ کرنے میں ناکامیاں درست کرنے کے لیے دستیاب فارم کو چھوڑ دیتی ہیں۔

<a id="edit-test-and-remove"></a>

## ترمیم کریں، جانچ کریں اور ہٹا دیں۔

منزل آرام پر خفیہ کردہ ہے۔ آپ اسے محفوظ کر سکتے ہیں، لیکن آپ اسے واپس نہیں پڑھ سکتے۔ ترمیم اس کے ذخیرہ شدہ اسناد کو
محفوظ رکھتی ہے جب تک کہ **منزل کی ترتیب کو تبدیل کریں** کو منتخب نہ کیا جائے۔ چینل کی قسم کو تبدیل نہیں کیا جا سکتا؛ اس
کے بجائے ایک نیا چینل بنائیں۔**ری کنفیگریشن کی ضرورت ہے** کے نشان والے ایک منتقل شدہ چینل کو اس وقت تک دوبارہ فعال نہیں
کیا جاسکتا جب تک کہ اس کی منزل کو تبدیل نہ کیا جائے۔ براؤزر پش چینلز صارف کی رکنیت استعمال کرتے ہیں اور ٹرانسپورٹ کی
منزل کے راز کو مسترد کرتے ہیں۔

ترتیب شدہ منزل پر حقیقی اطلاع بھیجنے کے لیے قطار ٹیسٹ کی کارروائی کا استعمال کریں۔ یہ فراہم کنندہ کے ڈیٹا میں ترمیم نہیں
کرتا ہے۔ [ترسیل کی تاریخ](/docs/v1.0/notification-history) میں نتیجہ کا جائزہ لیں۔ ڈیلیوری کو روکنے کے لیے چینل کو غیر
فعال کریں، یا جب مزید ضرورت نہ ہو اسے حذف کریں۔ حذف کرنے کا عمل فوری طور پر ہوتا ہے۔ کبھی بھی اسناد کو اسکرین شاٹس یا
سپورٹ رپورٹس میں چسپاں نہ کریں۔

ای میل، Gotify، ntfy، Discord، اور حسب ضرورت منزلیں API کے بنڈل Apprise CLI کا استعمال کرتی ہیں۔ علیحدہ Apprise سرور کی
ضرورت نہیں ہے۔ اگر کوئی درخواست ناکام ہوجاتی ہے تو، API کی بازیابی کے بعد دوبارہ کوشش کریں۔ خالی فہرست کا مطلب ہے کہ
کوئی نظر آنے والا کنفیگرڈ چینل فلٹرز سے مماثل نہیں ہے۔ فلٹرز صاف کریں یا چینل بنائیں۔ ڈیلیوری کی ناکامی کی تفصیلات میں
صرف حساس معلومات سے پاک خرابی کے پیغامات ہوتی ہیں۔
