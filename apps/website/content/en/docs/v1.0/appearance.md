## Color mode

Open the user menu's theme/appearance control and choose **System**, **Light**, or **Dark**. System follows the
browser's operating-system color preference. Light and Dark select a fixed theme. The browser remembers the preference
locally; another device can use a different mode. Changing the theme does not alter repository data, account roles, or
provider settings.

The website has its own theme control and browser preference, separate from the application. Documentation screenshots
use light/dark variants where available. If a device changes its system theme while System is selected, the interface
follows that preference. Verify browser storage availability if the preference does not survive a reload.

<a id="layout-and-keyboard-controls"></a>

## Layout and keyboard controls

Sidebar collapse and responsive navigation preserve the same permitted destinations. Open keyboard-shortcut help from
the user menu or press `?`. `/` opens search; `Meta+K` opens the command palette when keyboard shortcuts are applicable.
The command palette includes permitted navigation and administrator shortcuts for adding providers/repositories.
