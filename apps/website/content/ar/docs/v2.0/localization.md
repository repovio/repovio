تقوم Repovio بشحن واجهة الويب الخاصة بها باللغات الإنجليزية (`en`)، والألمانية (`de`)، والإسبانية (`es`)، والفرنسية
(`fr`)، والإيطالية (`it`)، والهولندية (`nl`)، والبولندية (`pl`)، والبرتغالية. (`pt`). قائمة اللغة الموجودة في رأس
التطبيق متاحة لكل مستخدم قام بتسجيل الدخول. يؤدي اختيار اللغة إلى حفظ التفضيل في ملف تعريف الارتباط للمتصفح
`repovio-locale` وتطبيقه على الزيارات المستقبلية.

اللغة الإنجليزية هي الافتراضي الحتمي والاحتياطي. عندما لا يحدد تفضيل المتصفح أو ملف تعريف الارتباط المحفوظ لغة محلية
مدعومة، يعرض Repovio اللغة الإنجليزية. يستخدم تنسيق التاريخ والوقت والأرقام اللغة المحددة.

<a id="sign-in-controls-and-language-flags"></a>

## عناصر تسجيل الدخول وأعلام اللغات

توفر صفحتا تسجيل الدخول وإعداد المسؤول الأول محدد لغة أسفل النموذج يعرض اللغة النشطة وعلمها. يظل مشغولًا أثناء تحميل
اللغة. زر منفصل يبدل بين سمة النظام والفاتحة والداكنة ويحفظ التفضيل. أيقونته تعرض التفضيل الحالي؛ التلميح والاسم الميسر
يصفان التفضيل الحالي والإجراء التالي.

تعرض القائمة أعلام SVG محلية زخرفية بجوار الأسماء الأصلية للغات. تظل الأسماء التسميات الميسرة ولا تستبدلها الأعلام.
مطابقة اللغة للبلد هي: `en` → GB, `de` → DE, `es` → ES, `fr` → FR, `it` → IT, `nl` → NL, `pl` → PL, `pt` → PT.

ملفات `apps/web/public/flags` من [flag-icons v7.5.0](https://github.com/lipis/flag-icons/tree/v7.5.0) وفق ترخيص MIT
المرفق. لا تتطلب طلبات صور خارجية. عند إضافة لغة أضف العلم ومطابقته في `useLocales` أيضًا.

<a id="adding-or-updating-a-locale"></a>

## إضافة أو تحديث لغة

1. أضف أو قم بتحديث `apps/web/i18n/locales/<locale>.json` باستخدام `en.json` كمرجع رئيسي كامل.
2. قم بتسجيل رمز اللغة المحلي واسم الملف واسم العرض الأصلي في `apps/web/nuxt.config.ts`.
3. احتفظ بجميع مفاتيح الرسائل في `en.json`؛ تتحقق مجموعة اختبار الويب من هذا التكافؤ لكل لغة يتم شحنها.
4. أضف رسائل باللغة الإنجليزية والألمانية لكل سلسلة واجهة جديدة مرئية للمستخدم، ثم أضف الترجمة المقابلة لكل لغة يتم
   شحنها.
5. قم بتشغيل `pnpm --filter @repovio/web test`، و`pnpm --filter @repovio/web typecheck`، واختبار Playwright المتأثر.

تظل أسماء الموفرين وأسماء المستودعات وأسماء سير العمل والبيانات الأخرى التي يوفرها الموفر دون تغيير لأنها ليست نسخة
واجهة Repovio.
