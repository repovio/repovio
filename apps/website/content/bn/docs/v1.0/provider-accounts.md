> আর্কাইভ সোর্স স্ন্যাপশট। পণ্য লেবেল Repovio ব্যবহার করে। অপরিবর্তিত এই রিলিজের ট্যাগ করা ডিপ্লয়মেন্ট ফাইল থেকে
> কনফিগারেশন শনাক্তকারী এবং কন্টেইনার রেফারেন্স ব্যবহার করুন।

<a id="access-and-list"></a>

## অ্যাক্সেস এবং তালিকা

সিস্টেম অ্যাডমিনিস্ট্রেটররা **প্রশাসন → প্রদানকারী অ্যাকাউন্ট** খোলে। টেবিলটি নাম, প্রদানকারীর ধরন, বেস ইউআরএল, সক্রিয়
অবস্থা এবং শেষ সিঙ্ক দেখায়। প্রকার/সক্ষম, বাছাই করুন, কলাম পরিবর্তন করুন এবং পৃষ্ঠায় স্থানান্তর করুন। অন্যান্য ভূমিকা
প্রদানকারী অ্যাকাউন্ট পরিচালনা করে না। তালিকার ডেটাতে টোকেন এবং OAuth গোপনীয়তাগুলি কখনই ফেরত দেওয়া হয় না।

<a id="connect-a-provider"></a>

## একটি প্রদানকারীকে সংযুক্ত করুন

**অ্যাড প্রোভাইডার** বেছে নিন এবং GitHub, GitLab, Forgejo বা Gitea বেছে নিন। একটি স্বীকৃত নাম এবং সঠিক উদাহরণ বেস URL
লিখুন; Gitea এর জন্য একটি প্রয়োজন৷ কনফিগার করা হিসাবে API রিপোর্টগুলি প্রমাণীকরণ পদ্ধতিগুলি থেকে চয়ন করুন৷ একটি
ম্যাচিং OAuth ক্লায়েন্ট ছাড়া, একটি ব্যক্তিগত অ্যাক্সেস টোকেন ব্যবহার করুন।**প্রদানকারীকে যাচাই করুন এবং যোগ করুন**
সেগুলি সংরক্ষণ করার আগে PAT শংসাপত্রগুলি পরীক্ষা করে।**কানেক্ট প্রোভাইডার** প্রদানকারীর সম্মতিতে রিডাইরেক্ট করে এবং
সফলতা বা ব্যর্থতার নোটিশ দিয়ে ফিরে আসে।

[প্রদানকারী OAuth সেটআপ](/docs/v1.0/provider-oauth) এ শুধুমাত্র পড়ার সুযোগ ব্যবহার করুন। প্রদানকারী OAuth সংগ্রহস্থল
ডেটা সংযোগ করে; এটি [OIDC ব্যবহারকারী সাইন-ইন করুন](/docs/v1.0/authentication) থেকে আলাদা। Repovio শংসাপত্রগুলিকে
বিশ্রামে এনক্রিপ্ট করে এবং কখনই প্রদানকারীর সংস্থান মিউটেশন প্রদান করে না, এমনকি যখন একটি আপস্ট্রিম টোকেন লেখার অনুমোদন
দিতে পারে।

<a id="maintain-connections"></a>

## সংযোগ বজায় রাখুন

অংশগ্রহণ নিয়ন্ত্রণ করতে একটি সারি সক্ষম বা অক্ষম করুন। মুলতুবি থাকা সারি ক্রিয়াগুলি অনুরোধগুলি শেষ হওয়ার সময়
বিরোধপূর্ণ ক্রিয়াগুলিকে অবরুদ্ধ করে৷ অক্ষম করা কনফিগারেশন ধরে রাখে। মুছে ফেলা অবিলম্বে কার্যকর হয়; ডিলিট অ্যাকশন
নির্বাচন করার আগে নির্ভরশীল ট্র্যাক করা ডেটা বিবেচনা করুন। একটি প্রতিস্থাপন সংযোগ তৈরি করুন যদি প্রদানকারীর মালিকানা বা
শংসাপত্রগুলি একটি প্রবাহের মাধ্যমে পরিবর্তিত হয় যা বর্তমান স্ক্রীনটি প্রকাশ করে না।

[ভান্ডার](/docs/v1.0/repositories) থেকে আলাদাভাবে সংগ্রহস্থল যোগ করুন; ওয়েবহুক কনফিগারেশন পৃথক ট্র্যাক করা সংগ্রহস্থলের
অন্তর্গত, প্রদানকারী অ্যাকাউন্ট নয়। খালি আবিষ্কার মানে কোনো সংগ্রহস্থল, একটি ভুল উদাহরণ, অপর্যাপ্ত পড়ার সুযোগ, বা অবৈধ
প্রমাণপত্রাদি। প্রমাণীকরণ-বিকল্প লোডিং ব্যর্থতা, যাচাইকরণ ত্রুটি, OAuth কলব্যাক নোটিশ এবং API ব্যর্থতার পার্থক্য করুন;
পুনরায় চেষ্টা করার আগে কারণ সংশোধন করুন। চলমান সিঙ্ক্রোনাইজেশন ব্যর্থতার জন্য কাজগুলি পরিদর্শন করুন।
