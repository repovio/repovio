> لقطة المصدر المؤرشفة. تستخدم ملصقات المنتجات Repovio. استخدم معرفات التكوين ومراجع الحاوية من ملفات النشر ذات العلامات
> لهذا الإصدار دون تغيير.

يعرض Repovio نقطة نهاية بروتوكول سياق النموذج عديمة الحالة عند `/mcp`. فهو يوفر وصولاً للقراءة فقط إلى نفس المستودعات،
وعمليات تشغيل سير العمل، وقوائم انتظار الفشل، وقوائم انتظار الموافقة، والملخصات، والاتجاهات التي قد يراها المستخدم
المصادق عليه في Repovio.

يقرأ خادم MCP قاعدة بيانات Repovio المحلية. ولا يستدعي واجهات برمجة التطبيقات الخاصة بموفر الخدمة، أو يبدأ المزامنة، أو
يوافق على سير العمل، أو يغير تكوين Repovio.

<a id="create-an-access-token"></a>

## إنشاء رمز وصول

افتح **الإعدادات**، وحدد علامة التبويب**MCP Access**، وقم بإنشاء رمز مميز مسمى. انتهاء الصلاحية اختياري. انسخ الرمز
المميز الكامل من مربع حوار الإنشاء لأن Repovio يعرضه مرة واحدة فقط ويخزن تجزئة SHA-256 الخاصة به فقط.

يسري إبطال الرمز المميز عند الطلب التالي. يؤدي حذف المستخدم أيضًا إلى حذف الرمز المميز. يتم تطبيق التغييرات على دور
المستخدم أو عضويات المستودع على الفور لأن كل طلب يحل التفويض الحالي من قاعدة البيانات.

<a id="configure-a-client"></a>

## تكوين العميل

استخدم أصل Repovio العام متبوعًا بـ `/mcp` وأرسل الرمز المميز في رأس التفويض:

```text
URL: https://repovio.example.com/mcp
Authorization: Bearer ezrepo_mcp_REPLACE_WITH_TOKEN
```

يستهدف الإصدار الأول عملاء MCP الذين يدعمون رؤوس HTTP المخصصة، مثل المحرر وعملاء سطر الأوامر. ولا يوفر اكتشاف OAuth ولا
يطالب بالتوافق مع الأجهزة المضيفة التي تتطلب التدفق MCP OAuth.

لا تضع الرمز المميز مطلقًا في عنوان URL أو معلمة استعلام أو ملف تكوين متعقب أو سجل الصدفة أو السجل. تفضل التخزين السري
للعميل أو متغير البيئة الذي لم يتم إصداره.

<a id="available-tools"></a>

## الأدوات المتاحة

| أداة                     | الغرض                                                                 |
| ------------------------ | --------------------------------------------------------------------- |
| `list_repositories`      | قم بإدراج المستودعات المتعقبة المرئية.                                |
| `get_repository`         | اقرأ مستودعًا واحدًا متتبعًا مرئيًا.                                  |
| `list_workflow_runs`     | الاستعلام عن تشغيل سير العمل المرئي المطبيع.                          |
| `list_needs_attention`   | قم بإدراج سياقات سير العمل التي فشل تشغيل المحطة الطرفية الأحدث فيها. |
| `list_awaiting_approval` | قم بإدراج عمليات التشغيل المرئية الحالية في انتظار موافقة المزود.     |
| `get_dashboard_summary`  | تلخيص سلامة سير العمل المرئية لنطاق زمني شامل.                        |
| `get_workflow_trend`     | تجميع دلاء اتجاهات النجاح والفشل المرئية.                             |

أدوات القائمة الافتراضية هي 25 نتيجة لكل صفحة وتقبل 100 نتيجة على الأكثر. تحتوي مخرجات الأداة على JSON منظم وتمثيل نصي
مطابق. تستخدم التواريخ قيم ISO 8601 UTC.

لا يعلن الخادم عمدًا عن أي موارد أو مطالبات أو مهام أو اشتراكات أو إجراءات الموفر أو أدوات التكوين الخاصة بـ MCP.

<a id="reverse-proxy-requirements"></a>

## عكس متطلبات الوكيل

- قم بتوجيه `POST /mcp` إلى حاوية API دون إعادة كتابته إلى `/api/v1/mcp`.
- الأمام `Authorization`، `Origin`، `Content-Type`، `Accept`، `MCP-Protocol-Version`، `Mcp-Method`، و`Mcp-Name`.
- استخدم TLS في الوكيل العكسي ولا تقم بتسجيل رؤوس التفويض أو طلب سلاسل الاستعلام.
- أضف كل أصل متصفح مسموح به إلى `CORS_ORIGIN`. تظل الطلبات التي لا تحتوي على رأس `Origin` مدعومة للعملاء الأصليين؛ يجب
  أن تتطابق الأصول الحالية مع القائمة المسموح بها التي تم ضبطها.

<a id="token-administration"></a>

## إدارة الرمز المميز

يقوم المستخدمون بإدارة الرموز المميزة الخاصة بهم في علامة التبويب **MCP Access** ضمن الإعدادات. يمكن لمسؤولي النظام فحص
البيانات التعريفية للرمز المميز الآمن وإلغاء الرمز المميز من صفحة المستخدمين، لكن لا يمكنهم استرداد التجزئة أو سر النص
العادي ولا يمكنهم إنشاء رمز مميز نيابة عن مستخدم آخر.

<a id="manage-token-states"></a>

## إدارة حالات الرمز المميز

تعرض قائمة الرموز المميزة الاسم والحالة والبادئة الآمنة والطوابع الزمنية التي تم إنشاؤها/آخر استخدام وانتهاء الصلاحية
الاختياري. يمكن أن تحتوي الأسماء على 100 حرف على الأكثر. الإلغاء يتطلب التأكيد. لا يمكن للرمز المميز الذي تم إبطاله أو
انتهاء صلاحيته مصادقة الطلبات المستقبلية. القائمة الفارغة تعني عدم وجود رموز مميزة للمستخدم؛ خطأ في التحميل يعرض إعادة
المحاولة. انسخ الرمز المميز الجديد بالكامل قبل إغلاق عرضه لمرة واحدة. تسمح مربعات حوار الرمز المميز للمسؤول
بالإدراج/الإلغاء فقط، ولا تسمح مطلقًا بالإنشاء لمستخدم آخر.
