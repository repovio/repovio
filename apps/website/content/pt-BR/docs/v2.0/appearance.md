<a id="color-mode"></a>

## Modo de cor

Abra o controle de tema/aparência do menu do usuário e escolha **Sistema**,**Claro** ou**Escuro**. O sistema segue a
preferência de cores do sistema operacional do navegador. Claro e Escuro selecionam um tema fixo. O navegador lembra a
preferência localmente; outro dispositivo pode usar um modo diferente. A alteração do tema não altera os dados do
repositório, as funções da conta ou as configurações do provedor.

O site possui controle de tema e preferência de navegador próprios, separados do aplicativo. As capturas de tela da
documentação usam variantes claro/escuro quando disponíveis. Se um dispositivo alterar o tema do sistema enquanto
Sistema estiver selecionado, a interface seguirá essa preferência. Verifique a disponibilidade de armazenamento do
navegador se a preferência não sobreviver a uma recarga.

<a id="layout-and-keyboard-controls"></a>

## Layout e controles de teclado

O colapso da barra lateral e a navegação responsiva preservam os mesmos destinos permitidos. Abra a ajuda dos atalhos de
teclado no menu do usuário ou pressione `?`. `/` abre pesquisa; `Meta+K` abre a paleta de comandos quando atalhos de
teclado são aplicáveis. A paleta de comandos inclui navegação permitida e atalhos de administrador para adicionar
provedores/repositórios.
