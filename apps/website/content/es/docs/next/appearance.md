<a id="color-mode"></a>

## Modo de color

Abra el control de tema/apariencia del menú de usuario y elija **Sistema**,**Claro** u**Oscuro**. El sistema sigue la
preferencia de color del sistema operativo del navegador. Claro y Oscuro seleccionan un tema fijo. El navegador recuerda
la preferencia localmente; otro dispositivo puede usar un modo diferente. Cambiar el tema no altera los datos del
repositorio, las funciones de la cuenta ni la configuración del proveedor.

El sitio web tiene su propio control de temas y preferencias de navegador, independientes de la aplicación. Las capturas
de pantalla de la documentación utilizan variantes claras/oscuras cuando estén disponibles. Si un dispositivo cambia el
tema del sistema mientras se selecciona Sistema, la interfaz sigue esa preferencia. Verifique la disponibilidad de
almacenamiento del navegador si la preferencia no sobrevive a una recarga.

<a id="layout-and-keyboard-controls"></a>

## Controles de diseño y teclado

El colapso de la barra lateral y la navegación receptiva conservan los mismos destinos permitidos. Abra la ayuda de
métodos abreviados de teclado desde el menú de usuario o presione `?`. `/` abre la búsqueda; `Meta+K` abre la paleta de
comandos cuando se aplican atajos de teclado. La paleta de comandos incluye navegación permitida y accesos directos de
administrador para agregar proveedores/repositorios.
