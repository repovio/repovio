## スコープと日付範囲

すべてのカードとチャートは、サインインしたユーザーが読み取ることができるリポジトリのみを使用します。過去の統計については、**過去 7 日間**、**過去 30 日間**、または**過去 90 日間**を選択します。時間範囲により、完了した実行の合計、成功/エラーの傾向、期間、およびステータスの分布が変化します。現在のキューと作業項目の数は、現在の状態の概要のままです。 [**更新**] を選択してダッシュボードをリロードします。コントロールは、要求が安定するまでビジー状態を保ちます。

<a id="summary-and-navigation"></a>

## 概要とナビゲーション

ワークフローの概要には、成功率/完了数、アクティブなキューに入れられた数/実行中の数、完了期間の中央値、現在の失敗数、承認待ちの数、および実行時間の合計が含まれます。現在の失敗を追跡して、
[注意が必要です](/docs/v1.0/needs-attention)、または承認待ち
[承認待ち](/docs/v1.0/awaiting-approval)。発行およびプルリクエストの概要は、独自のフィルター処理されたリストにリンクされています。マネージャーと管理者は、管理するリポジトリのセキュリティ アラートの概要も確認できます。

アクティブランカードは取り外し可能なカードを開きます。 `preset=active`
フィルター;現在の作業項目カードでは、リムーバブル プリセットも開きます。手動でフィルターを変更すると、プリセットが解放されます。

傾向グラフは、成功した実行と失敗した完了実行を時間の経過とともに比較します。ステータス分布グループの正規化された状態。
**最新の実行**
には、最近のワークフロー アクティビティがプロバイダーへのリンクとともに表示されます。これは埋め込みプロバイダー ログ ビューアではありません。 Repovio ダッシュボード ウィジェットからワークフローを承認または再実行することはできません。
