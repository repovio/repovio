## Préférence d'application

Chaque utilisateur connecté peut sélectionner une langue dans le menu Contrôle de langue/utilisateur de l'application.
L'application prend en charge l'anglais (`en`), l'allemand (`de`), l'espagnol (`es`), le français (`fr`), l'italien
(`it`), le néerlandais (`nl`), le polonais (`pl`) et le portugais (`pt`). La langue sélectionnée affecte les messages de
l'interface et le formatage de la date, de l'heure et des nombres. Les noms de référentiel, les noms de flux de travail
et les descriptions fournis par le fournisseur restent inchangés.

Le navigateur stocke la préférence dans `ezrepo-locale` pour les visites futures. L'anglais est la valeur déterministe
par défaut et la solution de secours pour les valeurs non prises en charge. Un autre navigateur/appareil a ses propres
préférences. Si une modification ne peut pas être effectuée, réessayez une fois la navigation rétablie. Voir
[Localisation](/docs/v1.0/localization) pour gérer les traductions d'application.

<a id="website-and-handbook"></a>

## Site Web et manuel

Le site Web et le manuel proposent 13 langues indépendamment des huit langues de l'interface de l'application. Utilisez
le sélecteur de langue du site Web pour conserver la version et la page actuelles de la documentation tout en changeant
de langue. L'arabe et l'ourdou utilisent une disposition de droite à gauche. Les captures d'écran peuvent afficher
l'application en anglais même lorsque le texte environnant est traduit ; les légendes des images identifient ce choix.
Le choix d'une langue de documentation ne l'ajoute pas à l'application.
