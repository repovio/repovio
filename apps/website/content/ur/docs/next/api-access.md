## انسٹال کردہ API دستاویزات

ہر Repovio API سرور `/docs` پر اپنی انٹرایکٹو API دستاویزات پیش کرتا ہے۔ مقامی ترقی میں، `http://localhost:3001/docs`
کھولیں۔ REST اینڈ پوائنٹ `/api/v1` بیس پاتھ کا استعمال کرتے ہیں۔

تعیناتی کے لیے، بیرونی طور پر قابل رسائی API کی اصل اور اپنے ریورس پراکسی کے ذریعے تشکیل کردہ راستہ استعمال کریں۔ مثال
کے طور پر، اگر API سرور `https://repovio.example.com` پر ظاہر ہوتا ہے، تو اس کی دستاویزات کو
`https://repovio.example.com/docs` پر ظاہر کیا جا سکتا ہے۔ ویب ایپلیکیشن اس راستے کو خود بخود پراکسی نہیں کرتی ہے۔ اگر
آپ اسے بے نقاب کرنا چاہتے ہیں تو اپنی پراکسی کو واضح طور پر ترتیب دیں۔ `/api/v1/docs` دستاویزات کا راستہ نہیں ہے۔

انسٹال شدہ حوالہ چل رہی ایپلیکیشن کی وضاحت کرتا ہے۔ اس انٹرایکٹو حوالہ سے کی گئی درخواستیں آپ کی مثال کا استعمال کرتی
ہیں اور ہر آپریشن کے لیے دستاویزی تصدیق اور اجازت کی ضرورت ہوتی ہے۔ سائن ان اور اکاؤنٹ کنفیگریشن کے لیے
[تصدیق](/docs/next/authentication) دیکھیں۔ MCP رسائی ٹوکنز [MCP کلائنٹس](/docs/next/mcp) کے لیے ہیں، عام REST بیئرر ٹوکن
کے طور پر نہیں۔

## جامد ریلیز کا حوالہ

اس ویب سائٹ پر [API حوالہ](/docs/next/api-reference) منتخب ریلیز کے عین اطلاق پر نظرثانی سے تیار کردہ صرف پڑھنے کے لیے
سنیپ شاٹ ہے۔ اسے چلانے والے Repovio مثال کی ضرورت نہیں ہے اور API کی درخواستیں نہیں بھیجتا ہے۔ اپنی انسٹالیشن سے مماثل
ورژن منتخب کریں۔ انسٹال شدہ `/docs` صفحہ آپ کی چل رہی تعمیر کے لیے مستند رہتا ہے۔

طریقہ، راستہ، یا تفصیل کے لحاظ سے تلاش کریں، پیرامیٹرز اور رسپانس اسکیموں کا معائنہ کریں، یا حوالہ صفحہ سے مکمل OpenAPI
JSON ڈاؤن لوڈ کریں۔ اسکیما شناخت کنندگان اور API کی وضاحتیں تیار کردہ معاہدے کی زبان کو برقرار رکھتی ہیں۔
