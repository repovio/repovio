## 侧边栏

**概述** 包含仪表板、工作流程运行、问题、拉取请求和支持的安全警报。**操作**包含存储库、作业和通知。**管理**
包含系统管理员的提供商帐户、用户和设置。工作流程运行扩展到所有运行、等待批准和需要注意；通知导航公开频道，对于管理员来说，还公开传送历史记录。

侧边栏仅提供您的角色可以访问的目的地。安全警报需要管理权限。折叠侧边栏会保留标记的目的地。在窄屏幕上，使用导航控件打开侧边栏。该手册记录了每个角色领域，即使您的帐户看不到它。

<a id="status-and-search"></a>

## 状态和搜索

使用应用栏中的 [搜索](/docs/v2.0/search)
查找目的地和同步资源。状态栏报告 API 连接、同步活动和正在运行的工作流程计数。其运行工作流计数器打开
[同步任务](/docs/v2.0/guide-jobs)；同步活动可以包括项目进度。连接恢复刷新状态。断开连接的指示器意味着实时更新可能已过时；在依赖显示的计数之前检查 API 并重试。

<a id="user-menu-and-footer"></a>

## 用户菜单和页脚

用户菜单打开个人
[设置](/docs/v2.0/settings)、语言和外观控件，然后注销。页脚链接到项目和手册。选择显示的版本将打开更改日志对话框。其发行说明和更新指示器有助于识别可用版本；应用升级仍然是部署操作。提供者链接打开外部资源。那里的操作需要提供商自己的权限，并且在 Repovio 之外。

<a id="table-controls"></a>

## 共享表控件

如果提供，表格选项可配置列可见性、排序和固定；操作列保持固定在右侧。选项在浏览器中保留每个表。分页使用页面查询。工作流程、问题、拉取请求和警报列表从 25 行开始；作业、存储库、提供者、用户、渠道和交付历史记录从 10 开始。加载选项时可以禁用过滤器控件。清除仪表板预设或更改过滤器以返回您自己的查询。这些控件更改本地视图，而不更改提供者记录。
