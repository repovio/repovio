> 存档源快照。产品标签使用Repovio。使用此版本标记部署文件中的配置标识符和容器引用，保持不变。

<a id="choose-an-image"></a>

## 选择一张图片

每个登录用户（包括 OIDC 用户）都可以打开 **设置 → 常规** 并上传最多 2 MiB 的 JPEG、PNG 或 WebP。或者从公共 HTTPS
URL 导入图像。非方形图像会打开裁剪对话框；选择方形裁剪并在上传前确认。取消对话框会使当前头像保持不变。

Repovio 剥离图像元数据，渲染 256 × 256
WebP，并仅将该标准化图像存储在 PostgreSQL 中。它不保留原始图像或远程 URL。类型无效、图片过大、导入失败、解码失败、上传失败分别报错；选择支持的图像或修复源/连接后重试。

<a id="remove-and-display"></a>

## 删除并显示

使用删除操作删除当前图片。删除失败后，现有头像可供重试。如果没有图片，界面会根据个人姓名或用户名显示缩写。存储库成员头像组最多显示五个成员并汇总其他成员。头像可见性遵循包含资源的权限。更改 Repovio 头像不会更新您的提供商个人资料图片。
