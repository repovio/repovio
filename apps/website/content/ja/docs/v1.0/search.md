<a id="search-the-installation"></a>

## インストールを検索する

アプリバーから検索を開くか、表示されたキーボード ショートカットを使用します。少なくとも 2 文字を入力してください。結果は、ナビゲーションの宛先、リポジトリ、プロバイダー アカウント、およびワークフローの実行にグループ化されます。ナビゲーション マッチでは、アカウントがアクセスできる宛先の翻訳されたラベルが使用されます。リソースの結果では、同期されたプロバイダー名が使用されます。

キーボードを使用して結果間を移動するか、ポインターを使用して結果を選択します。リポジトリとプロバイダー アカウントが一致すると、対応する Repovio ビューが開きます。ワークフローが一致すると、プロバイダーの実行 URL が開きます。
**Escape** を押して検索を終了し、前のページに戻ります。検索では、プロバイダー側​​の検出や同期の開始は実行されません。

<a id="access-and-failure-states"></a>

## アクセスと障害の状態

リソース検索では、現在のユーザーのリポジトリ権限が使用されます。プロバイダー アカウントの結果は管理者に限定されます。結果が得られない場合は、クエリが短い、一致する保持レコードがない、またはメンバーシップが不十分であることを意味する可能性があります。より具体的な名前を試し、同期されたデータが欠落しているかどうかリポジトリ/ジョブを検査してください。クエリの実行中に読み込み中が表示されます。リクエスト エラーが発生した場合は、API 接続が回復した後にクエリを再試行します。検索によってプロバイダー トークンや通知資格情報が明らかになることはありません。
