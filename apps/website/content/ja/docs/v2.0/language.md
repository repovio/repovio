## アプリケーションの設定

サインインしているすべてのユーザーは、アプリケーションの言語コントロール/ユーザー メニューから言語を選択できます。アプリケーションは英語をサポートしています（`en`)、ドイツ語 (`de`)、スペイン語 (`es`)、フランス語 (`fr`)、イタリア語 (`it`)、オランダ語 (`nl`)、ポーランド語 (`pl`)、ポルトガル語 (`pt`）。選択した言語は、インターフェイス メッセージと日付、時刻、数値の形式に影響します。プロバイダーが提供するリポジトリ名、ワークフロー名、説明は変更されません。

ブラウザは設定を次の場所に保存します `repovio-locale`
今後の訪問のために。英語は決定的なデフォルトであり、サポートされていない値のフォールバックです。別のブラウザ/デバイスには独自の設定があります。変更を完了できない場合は、ナビゲーションが回復してから再試行してください。見る
[ローカリゼーション](/docs/v2.0/localization) アプリケーションの翻訳を維持するため。

<a id="website-and-handbook"></a>

## ウェブサイトとハンドブック

Web サイトとハンドブックでは、アプリケーションの 8 つのインターフェイス言語とは別に、13 の言語が提供されています。 Web サイトの言語セレクターを使用して、言語を切り替えるときに現在のドキュメントのバージョンとページを保持します。アラビア語とウルドゥー語は右から左のレイアウトを使用します。周囲のテキストが翻訳されている場合でも、スクリーンショットには英語のアプリケーションが表示されます。画像のキャプションでその選択肢がわかります。ドキュメント言語を選択しても、それはアプリケーションに追加されません。
