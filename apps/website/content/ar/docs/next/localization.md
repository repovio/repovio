يدعم Repovio جميع لغات الموقع الثلاث عشرة، ويحتفظ بترجماته الحالية إلى الإيطالية والهولندية والبولندية والبرتغالية.
يوفر التطبيق 17 لغة: الإنجليزية والألمانية والإسبانية والفرنسية والإيطالية والهولندية والبولندية والبرتغالية والصينية
المبسطة والهندية والعربية والبنغالية والبرتغالية البرازيلية والإندونيسية والأردية والروسية واليابانية. تظل البرتغالية
(`pt`) والبرتغالية البرازيلية (`pt-BR`) خيارين منفصلين.

الإنجليزية هي اللغة الافتراضية والاحتياطية. تكون الأولوية لملف تعريف الارتباط المحفوظ في المتصفح `repovio-locale` على
لغة المتصفح المدعومة؛ وتؤدي التفضيلات غير المدعومة إلى استخدام الإنجليزية. تحافظ تغييرات اللغة على المسار الحالي
ومعاملات الاستعلام. يتبع تنسيق التاريخ والوقت والأرقام اللغة المحددة مع الحفاظ على سياسات نظام 24 ساعة وتنسيق ISO
المُعَدّة.

تستخدم العربية والأردية تخطيطات من اليمين إلى اليسار، وتستخدم اللغات الأخرى تخطيطات من اليسار إلى اليمين. تحتفظ الأسماء
التي يكتبها الموفر ومعرّفات المستودعات وعناوين URL والشفرة بقيمها الأصلية واتجاهها المقروء.

<a id="sign-in-controls-and-language-flags"></a>

## عناصر تسجيل الدخول وأعلام اللغات

تعرض صفحات تسجيل الدخول وإعداد المسؤول الأول وقائمة المستخدم بعد تسجيل الدخول أسماء اللغات الأصلية نفسها وأعلام SVG
محلية زخرفية. تظل الأسماء هي التسميات الميسّرة. يمكن تمرير القوائم الطويلة والوصول إلى خياراتها بلوحة المفاتيح. يظل
عنصر التحكم الذي بدأ التغيير مشغولًا طوال تنزيل اللغة، ويُمنع تكرار الاختيار. إذا فشل التنزيل، يعيد Repovio اللغة السابقة
ويعرض خطأً مترجمًا. أعد تحميل الصفحة واختر اللغة مجددًا لإعادة محاولة تنزيل الملف الذي فشل تحميله.

توفر صفحات المصادقة العامة أيضًا زرًا للمظهر يتنقل بين النظام والفاتح والداكن. تعرض أيقونته التفضيل الحالي، ويصف التلميح
والاسم الميسّر التفضيل الحالي والإجراء التالي.

تكون مطابقة اللغة لبلد العلم كما يلي:

| اللغة | البلد | اللغة   | البلد |
| ----- | ----- | ------- | ----- |
| `en`  | GB    | `zh-CN` | CN    |
| `de`  | DE    | `hi`    | IN    |
| `es`  | ES    | `ar`    | SA    |
| `fr`  | FR    | `bn`    | BD    |
| `it`  | IT    | `pt-BR` | BR    |
| `nl`  | NL    | `id`    | ID    |
| `pl`  | PL    | `ur`    | PK    |
| `pt`  | PT    | `ru`    | RU    |
| `ja`  | JP    |         |       |

تأتي ملفات `apps/web/public/flags` من [flag-icons v7.5.0](https://github.com/lipis/flag-icons/tree/v7.5.0) بموجب
ترخيص MIT المرفق. لا تحتاج إلى خدمة خارجية للصور أو الترجمة.

<a id="adding-or-updating-a-locale"></a>

## إضافة لغة أو تحديثها

1. استخدم `apps/web/i18n/locales/en.json` مرجعًا حاليًا لجميع الرسائل. ترجم كل ملفات رسائل اللغات المضمّنة، بما فيها
   التسميات الميسّرة ورسائل التحقق وحالات الفراغ والخطأ والتحميل والمعاملات ومعاني صيغ الجمع.
2. سجّل البيانات الوصفية في `apps/web/shared/locales.ts`: الرمز المطابق ووسم اللغة واسمها الأصلي وملف الرسائل والاتجاه
   وبلد العلم ومعرّف لغة Nuxt UI. حافظ على الرموز الحالية وميّز بين `pt` و`pt-BR`.
3. اربط تصدير لغة Nuxt UI المثبّت في `apps/web/app/utils/locales.ts`؛ ومن أمثلته `zh_cn` و`pt_br`.
4. أضف ملف العلم المحلي المرخّص واحتفظ بنسبة المصدر. لا تستورد تنفيذ الموقع إلى التطبيق.
5. شغّل فحوص ملفات الرسائل وسيناريوهات المتصفح. تقارن الاختبارات سجل لغات الموقع الفعلي باللغات التي يدعمها التطبيق،
   وترفض الرسائل الناقصة والمعاملات غير المتوافقة والصياغة غير الصالحة وارتباطات لغات الواجهة المفقودة وملفات الأعلام
   المفقودة. لا يغني الرجوع إلى الإنجليزية عن إكمال الترجمة. يجوز إبقاء أسماء المنتجات والقيم التقنية الحرفية دون تغيير.

فعّل سلسلة الأدوات المثبّتة على Node.js 26.13.0 وpnpm 11.28.9، وشغّل التطبيق محليًا، ثم نفّذ:

```sh
corepack pnpm --dir apps/web test
corepack pnpm --dir apps/web lint
corepack pnpm --dir apps/web typecheck
corepack pnpm --dir apps/web exec playwright test tests/e2e/localization.spec.ts \
  tests/e2e/auth-preferences.spec.ts tests/e2e/localization-rtl.spec.ts
```

افحص لقطات الشاشة ذات الصلة بالمظهرين الفاتح والداكن والتخطيطات الضيقة والواسعة، وخصوصًا الكتابة من اليمين إلى اليسار
والنصوص الصينية واليابانية والكورية والنصوص الهندية. حدّث ترجمات الدليل الحالي `next` بصورة متسقة؛ وتبقى أرشيفات الإصدارات
المنشورة دون تغيير.
