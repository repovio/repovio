<a id="administrator-access"></a>

## Доступ администратора

Только системные администраторы могут открыть **Настройки → Система**. Загрузка показывает скелет; неудачная загрузка
приводит к ошибке и повторной попытке вместо редактируемых значений по умолчанию, полученных из отсутствующих данных.
Прежде чем сохранять изменения, дождитесь запроса настроек.

<a id="retention-defaults"></a>

## Срок хранения по умолчанию

Установите отдельные периоды хранения по умолчанию для запусков рабочих процессов, проблем и запросов на включение.
Каждое значение должно быть от 1 до 3650 дней. Репозиторий может независимо переопределять каждое соответствующее
значение; переопределение пустого репозитория восстанавливает системные значения по умолчанию. Срок хранения влияет на
локально хранящуюся историю, а не на записи на стороне поставщика. Сокращение срока хранения может привести к удалению
старых сохраненных данных, поэтому сначала проверьте требования к отчетности и расследованию.

Элементы управления хранением и отслеживанием репозитория описаны в [Репозитории](/docs/v2.0/repositories). Отсутствие
исторической строки может отражать сохранение, а не неудачную синхронизацию поставщика.

<a id="datetime-formatting"></a>

## Форматирование даты/времени

Установите формат даты/времени по умолчанию и проверьте его предварительный просмотр перед сохранением. Выбор локали
по-прежнему контролирует переведенный текст интерфейса и форматирование с учетом локали. Сохраните один раз; об успехе и
сбоях проверки/API сообщается отдельно. Повторите попытку после исправления или восстановления API. Предпочтение
форматирования никогда не меняет временные метки исходного поставщика.
