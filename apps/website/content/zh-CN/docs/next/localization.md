title: '界面本地化'
description: '支持的界面语言、回退行为以及维护 Repovio 翻译的过程。'
---

Repovio 支持网站提供的全部 13 种语言，同时保留现有的意大利语、荷兰语、波兰语和葡萄牙语翻译。
应用共提供 17 种语言：英语、德语、西班牙语、法语、意大利语、荷兰语、波兰语、葡萄牙语、简体中文、
印地语、阿拉伯语、孟加拉语、巴西葡萄牙语、印度尼西亚语、乌尔都语、俄语和日语。
葡萄牙语（`pt`）与巴西葡萄牙语（`pt-BR`）是两个独立的选项。

英语是默认语言，也是回退语言。已保存的 `repovio-locale` 浏览器 Cookie 优先于受支持的浏览器语言偏好；
不受支持的偏好会回退到英语。切换语言会保留当前路由和查询参数。
日期、时间和数字按所选语言的规则显示，同时遵循已配置的 24 小时制和 ISO 格式策略。

阿拉伯语和乌尔都语采用从右到左的布局，其他语言采用从左到右的布局。
提供商编写的名称、仓库标识符、URL 和代码保留原始值，并以便于阅读的方向显示。

<a id="sign-in-controls-and-language-flags"></a>

## 登录控件与语言旗帜

登录页、首位管理员设置页和登录后的用户菜单均显示相同的语言原生名称及装饰性本地 SVG 旗帜。
语言名称始终作为无障碍标签。较长的菜单可滚动，并支持键盘操作。
发起切换的控件会在语言资源下载完成前持续显示加载状态；此期间无法重复选择。
如果下载失败，Repovio 会恢复之前的语言并显示已本地化的错误消息。
要重试失败的资源下载，请重新加载页面，然后再次选择该语言。

公开的身份验证页面还提供主题按钮，可在跟随系统、浅色和深色之间循环切换。
图标表示当前偏好；工具提示和无障碍名称说明当前偏好及下一步操作。

语言区域与国旗所属国家的对应关系如下：

| 语言区域 | 国家 | 语言区域 | 国家 |
| -------- | ---- | -------- | ---- |
| `en`     | GB   | `zh-CN`  | CN   |
| `de`     | DE   | `hi`     | IN   |
| `es`     | ES   | `ar`     | SA   |
| `fr`     | FR   | `bn`     | BD   |
| `it`     | IT   | `pt-BR`  | BR   |
| `nl`     | NL   | `id`     | ID   |
| `pl`     | PL   | `ur`     | PK   |
| `pt`     | PT   | `ru`     | RU   |
| `ja`     | JP   |          |      |

`apps/web/public/flags` 中的资源来自
[flag-icons v7.5.0](https://github.com/lipis/flag-icons/tree/v7.5.0)，遵循随附的 MIT 许可证。
这些资源无需外部图片服务或翻译服务。

<a id="adding-or-updating-a-locale"></a>

## 添加或更新区域设置

1. 以 `apps/web/i18n/locales/en.json` 作为当前完整的消息参考。完整翻译每个随应用发布的消息目录，
   包括无障碍标签、验证消息、空白状态、错误状态、加载状态、参数，以及单复数表达的含义。
2. 在 `apps/web/shared/locales.ts` 中注册元数据：精确的代码、语言标签、原生名称、消息目录文件、文字方向、
   旗帜所属国家和 Nuxt UI 语言标识符。保留现有代码，并区分 `pt` 与 `pt-BR`。
3. 在 `apps/web/app/utils/locales.ts` 中映射已安装的 Nuxt UI 语言导出项，例如 `zh_cn` 和 `pt_br`。
4. 添加具有相应许可证的本地旗帜资源，并保留其署名信息。不要将网站的实现导入应用。
5. 运行消息目录检查和浏览器测试场景。测试将实际的网站语言注册表与应用支持的语言进行比较，
   并拒绝缺失的消息、不兼容的参数、格式错误的语法、缺失的 UI 映射和缺失的旗帜资源。
   英语回退不能代替完整翻译。产品名称和技术字面量保持原样是有效的。

启用固定版本的 Node.js 26.13.0 和 pnpm 11.28.9 工具链，启动本地应用，然后运行：

```sh
corepack pnpm --dir apps/web test
corepack pnpm --dir apps/web lint
corepack pnpm --dir apps/web typecheck
corepack pnpm --dir apps/web exec playwright test tests/e2e/localization.spec.ts \
  tests/e2e/auth-preferences.spec.ts tests/e2e/localization-rtl.spec.ts
```

检查浅色和深色主题、窄屏和宽屏布局下的相关截图，尤其注意从右到左的布局、中日韩文字及印度系文字。
同步更新当前 `next` 手册的各语言翻译；已发布的版本归档保持不变。
