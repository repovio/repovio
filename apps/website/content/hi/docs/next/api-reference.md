title: 'एपीआई संदर्भ'
description: 'इस Repovio रिलीज़ के लिए अंतिम बिंदु, पैरामीटर, अनुरोध निकाय और प्रतिक्रिया स्कीमा का अन्वेषण करें।'
---

यह केवल पढ़ने योग्य संदर्भ चयनित एप्लिकेशन रिलीज़ से उत्पन्न होता है। समापन बिंदु खोजने के लिए खोज फ़ील्ड का उपयोग करें;
नेस्टेड फ़ील्ड के लिए स्कीमा विवरण का विस्तार करें और आवश्यकता पड़ने पर संपूर्ण OpenAPI JSON डाउनलोड करें।

आपके इंस्टॉलेशन द्वारा प्रदान किए गए दस्तावेज़ के लिए, [एपीआई पहुंच](/docs/next/api-access) देखें।
