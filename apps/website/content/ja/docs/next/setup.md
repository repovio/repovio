<a id="before-setup"></a>

## セットアップ前

[導入](/docs/next/deployment)
を使用して、API、Web アプリケーション、および PostgreSQL をデプロイします。インストールURLを開きます。ユーザーが存在しない場合、Repovio はブラウザを
`/auth/setup`
に誘導します。既存のインストールではアカウントが保持され、代わりにサインインが開かれます。セットアップでは、プロバイダー アカウントではなく、ローカル Repovio アカウントが作成されます。

<a id="create-the-administrator"></a>

## 管理者を作成する

オプションの姓名、一意のユーザー名、パスワード、およびパスワードの確認を入力します。パスワードには 12 文字以上が必要です。セットアップ フォームを一度送信し、リクエストを待ちます。セットアップが成功すると、最初のシステム管理者がサインインします。検証エラーがあると、フォームは修正できる状態になります。別のオペレーターが最初にセットアップを完了した場合は、既存のアカウントを使用して
[サインイン](/docs/next/sign-in) に進みます。

<a id="continue-configuration"></a>

## 設定を続行します

[プロバイダーアカウント](/docs/next/provider-accounts) を接続し、[リポジトリ](/docs/next/repositories)
を選択して、[同期ジョブ](/docs/next/guide-jobs)
を検査します。ローカル ユーザーは、保護された API を通じて作成できます。 [ユーザー] ページにはアカウントがリストされ、削除と MCP アクセスが管理されます。あるいは、アイデンティティ プロバイダーが管理するアカウント用に
[OIDC](/docs/next/authentication) を構成します。新しい非管理者には、明示的なリポジトリ メンバーシップが必要です。

セットアップが失敗した場合は、認証情報を公開せずに API/データベースの可用性と展開ログを確認します。セットアップを繰り返すためにデータベースをリセットしないでください。既存のローカル管理者については、[パスワードの回復](/docs/next/authentication#reset-a-forgotten-password)
を参照してください。

<a id="local-user-and-group-management"></a>

## ローカルアカウントの作成とリセット

管理 → ユーザーの新規作成を選びます。一意なユーザー名、任意の氏名、12–256文字のパスワードと確認、役割を入力します。初期値は Viewer です。OIDC 有効時も作成できます。OIDC アカウントは提供元で登録され、ローカル名の一致では関連付けられません。
