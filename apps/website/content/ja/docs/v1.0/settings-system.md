<a id="administrator-access"></a>

## 管理者アクセス

**[設定] → [システム]**
を開くことができるのはシステム管理者のみです。ロードするとスケルトンが表示されます。ロードが失敗するとエラーが発生し、欠落データから推測される編集可能なデフォルトの代わりに再試行されます。変更を保存する前に、設定要求を待ってください。

<a id="retention-defaults"></a>

## 保持のデフォルト

ワークフローの実行、発行、プル リクエストに対して個別のデフォルトの保存期間を設定します。各値は 1 ～ 3650 日である必要があります。リポジトリは、対応する各値を個別にオーバーライドできます。空のリポジトリをオーバーライドすると、システムのデフォルトが復元されます。保持は、プロバイダー側​​の記録ではなく、ローカルに保存された履歴に影響します。保存期間を短縮すると、保存されている古いデータが削除される可能性があるため、最初にレポートと調査の要件を確認してください。

リポジトリの保持と追跡の制御については、[リポジトリ](/docs/v1.0/repositories)
に文書化されています。履歴行の欠落は、プロバイダーの同期の失敗ではなく、保持を反映している可能性があります。

<a id="datetime-formatting"></a>

## 日付/時刻の形式

デフォルトの日付/時刻形式を設定し、保存する前にライブ プレビューを確認します。ロケールの選択は、翻訳されたインターフェイス テキストとロケール依存の書式設定を引き続き制御します。一度保存してください。成功と検証/API の失敗は個別に報告されます。修正または API リカバリ後に再試行してください。フォーマット設定によって元のプロバイダーのタイムスタンプが変更されることはありません。
