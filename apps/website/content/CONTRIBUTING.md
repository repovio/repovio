# Contributing to Repovio

Use the issue forms for reproducible bugs, feature requests and questions. Documentation contributions belong in
[repovio/docs](https://github.com/repovio/docs). Include the application version, provider type and reproduction steps;
remove private repository names, tokens, credentials and personal data from examples and screenshots.

Write persisted project text in American English, with complete translations for every locale in `locales.json`.
Preserve commands, identifiers, examples, and explicit heading anchors across translations. Respect the target
repository's formatting, tests and approval requirements. Provider integrations must remain read-only. Application and
website source are private; community participation does not require publishing their source.

Report vulnerabilities privately according to [SECURITY.md](SECURITY.md). Support the project through
[Buy Me a Coffee](https://buymeacoffee.com/tobiaswaelde).
