## ইনস্টল করা API ডকুমেন্টেশন

প্রতিটি Repovio API সার্ভার `/docs` এ তার ইন্টারেক্টিভ API ডকুমেন্টেশন পরিবেশন করে। স্থানীয় উন্নয়নে,
`http://localhost:3001/docs` খুলুন। REST এন্ডপয়েন্ট `/api/v1` বেস পাথ ব্যবহার করে।

একটি স্থাপনার জন্য, বাহ্যিকভাবে পৌঁছানো যায় এমন API উত্স এবং আপনার বিপরীত প্রক্সি দ্বারা কনফিগার করা পথ ব্যবহার করুন৷
উদাহরণস্বরূপ, যদি API সার্ভার `https://repovio.example.com`-এ উন্মুক্ত হয়, তাহলে এর ডকুমেন্টেশন
`https://repovio.example.com/docs`-এ উন্মুক্ত করা যেতে পারে। ওয়েব অ্যাপ্লিকেশন স্বয়ংক্রিয়ভাবে এই রুট প্রক্সি করে না;
আপনার প্রক্সিটি স্পষ্টভাবে কনফিগার করুন যদি আপনি এটি প্রকাশ করতে চান। `/api/v1/docs` ডকুমেন্টেশন রুট নয়।

ইনস্টল করা রেফারেন্স চলমান অ্যাপ্লিকেশন বর্ণনা করে। সেই ইন্টারেক্টিভ রেফারেন্স থেকে করা অনুরোধগুলি আপনার উদাহরণ ব্যবহার
করে এবং প্রতিটি অপারেশনের জন্য নথিভুক্ত প্রমাণীকরণ এবং অনুমতি প্রয়োজন। সাইন-ইন এবং অ্যাকাউন্ট কনফিগারেশনের জন্য
[প্রমাণীকরণ](/docs/v2.0/authentication) দেখুন। MCP অ্যাক্সেস টোকেনগুলি [MCP ক্লায়েন্ট](/docs/v2.0/mcp) এর জন্য, সাধারণ
REST বহনকারী টোকেন হিসাবে নয়।

## স্ট্যাটিক রিলিজ রেফারেন্স

এই ওয়েবসাইটের [API রেফারেন্স](/docs/v2.0/api-reference) হল একটি পঠনযোগ্য স্ন্যাপশট যা নির্বাচিত রিলিজের সঠিক
অ্যাপ্লিকেশন সংশোধন থেকে তৈরি করা হয়েছে। এটির কোন চলমান Repovio উদাহরণের প্রয়োজন নেই এবং API অনুরোধ পাঠায় না। আপনার
ইনস্টলেশনের সাথে মিলে যাওয়া সংস্করণ নির্বাচন করুন; ইনস্টল করা `/docs` পৃষ্ঠাটি আপনার চলমান বিল্ডের জন্য প্রামাণিক রয়ে
গেছে।

পদ্ধতি, পথ বা বিবরণ দ্বারা অনুসন্ধান করুন, পরামিতি এবং প্রতিক্রিয়া স্কিমাগুলি পরিদর্শন করুন, অথবা রেফারেন্স পৃষ্ঠা থেকে
সম্পূর্ণ OpenAPI JSON ডাউনলোড করুন। স্কিমা শনাক্তকারী এবং API বিবরণ জেনারেট করা চুক্তির ভাষা ধরে রাখে।
