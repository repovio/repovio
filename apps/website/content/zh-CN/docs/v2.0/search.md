<a id="search-the-installation"></a>

## 搜索安装

从应用程序栏打开搜索或使用显示的键盘快捷键。输入至少两个字符。结果分为导航目的地、存储库、提供商帐户和工作流程运行。导航匹配使用您的帐户可以访问的目的地的翻译标签；资源结果使用同步的提供者名称。

使用键盘在结果中移动或使用指针选择一个。存储库和提供商帐户匹配会打开相应的 Repovio 视图；工作流程匹配打开提供程序运行 URL。按
**Escape** 关闭搜索并返回到上一页。搜索不执行提供者端发现或启动同步。

<a id="access-and-failure-states"></a>

## 访问和失败状态

资源搜索使用当前用户的存储库权限。提供商帐户结果仅限于管理员。没有结果可能意味着查询很短、没有匹配的保留记录或成员资格不足。尝试更具体的名称，并检查存储库/作业（如果同步数据丢失）。查询运行时会显示正在加载。如果出现请求错误，请在 API 连接恢复后重试查询。搜索永远不会泄露提供者令牌或通知凭据。
