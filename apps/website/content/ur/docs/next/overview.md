Repovio GitHub ایکشنز، GitLab پائپ لائنز، Forgejo ایکشنز اور Gitea ایکشنز کے لیے ایک خود میزبان ڈیش بورڈ ہے۔ منتخب ورک
فلو رنز، مسائل اور درخواستوں کو ٹریک کریں، موجودہ ناکامیوں کی نشاندہی کریں اور فراہم کنندہ کے وسائل میں ترمیم کیے بغیر
اطلاعات بھیجیں۔

<a id="one-permission-scoped-overview"></a>

## ایک اجازت کے دائرہ کار کا جائزہ

- ورک فلو کی صحت، تازہ ترین رنز، رجحانات، منظوری کی قطاروں اور کام کا معائنہ کریں جس پر توجہ دینے کی ضرورت ہے۔
- مسائل کو پڑھیں اور درخواستوں کو ان کے متعلقہ ورک فلو سرگرمی کے ساتھ کھینچیں یا انضمام کریں۔
- خفیہ اقدار کو ذخیرہ کیے بغیر تعاون یافتہ سیکیورٹی الرٹ میٹا ڈیٹا کا جائزہ لیں۔
- ذخیرہ کی رکنیت، خفیہ کردہ اطلاع کی منزلیں اور صرف پڑھنے کے لیے فراہم کنندہ کنکشنز کا نظم کریں۔
- مقامی اکاؤنٹس، اختیاری OpenID کنیکٹ اور ذاتی طور پر صرف پڑھنے کے لیے MCP رسائی ٹوکن استعمال کریں۔

فراہم کنندگان کی تبدیلیاں، منظورییں، جائزے اور ورک فلو دوبارہ چلنا بیرونی کارروائیاں رہیں۔ Repovio کا اپنا انتظامیہ
کنٹرول اس کی مقامی ٹریکنگ اور اطلاعات کو ترتیب دیتا ہے۔ وہ فراہم کنندہ کو تحریری رسائی نہیں دیتے ہیں۔
