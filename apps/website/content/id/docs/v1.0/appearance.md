<a id="color-mode"></a>

## Modus warna

Buka kontrol tema/tampilan menu pengguna dan pilih **Sistem**,**Terang**, atau**Gelap**. Sistem mengikuti preferensi
warna sistem operasi browser. Terang dan Gelap pilih tema tetap. Browser mengingat preferensi secara lokal; perangkat
lain dapat menggunakan mode yang berbeda. Mengubah tema tidak mengubah data repositori, peran akun, atau pengaturan
penyedia.

Situs web memiliki kontrol tema dan preferensi browser sendiri, terpisah dari aplikasi. Tangkapan layar dokumentasi
menggunakan varian terang/gelap jika tersedia. Jika perangkat mengubah tema sistemnya saat Sistem dipilih, antarmuka
akan mengikuti preferensi tersebut. Verifikasi ketersediaan penyimpanan browser jika preferensi tidak dapat bertahan
saat dimuat ulang.

<a id="layout-and-keyboard-controls"></a>

## Tata letak dan kontrol keyboard

Penciutan sidebar dan navigasi responsif mempertahankan tujuan yang diizinkan sama. Buka bantuan pintasan keyboard dari
menu pengguna atau tekan `?`. `/` membuka pencarian; `Meta+K` membuka palet perintah ketika pintasan keyboard dapat
diterapkan. Palet perintah mencakup navigasi yang diizinkan dan pintasan administrator untuk menambahkan
penyedia/repositori.
