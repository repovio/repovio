<a id="browse-and-filter"></a>

## تصفح وتصفية

افتح **نظرة عامة ← سحب الطلبات**. تستخدم القوائم والملخصات واختيارات التصفية والتفاصيل عضويات المستودع. البحث حسب
العنوان أو الرقم؛ التصفية حسب الموفر، والمستودع، ودورة الحياة، والمؤلف، والمتنازل له، وحالة المسودة، وحالة سير العمل،
ومتطلبات الموافقة، والتسميات، والوقت المحدث. حدود التاريخ المحدثة تشمل التوقيت العالمي المنسق (UTC). يجب أن تتطابق جميع
التصنيفات المحددة المتعددة. قم بتغيير الفرز والأعمدة المرئية والتقسيم إلى صفحات باستخدام عناصر تحكم الجدول. تحسب
البطاقات التلخيصية التغييرات المفتوحة والمسودات وعمليات سير العمل الفاشلة والموافقات على سير العمل. يستخدم GitLab مصطلح
طلب الدمج. تُظهر التفاصيل فروع المصدر/الهدف وحالة المسودة ودورة الحياة وحالة سير العمل المجمعة. يستخدم التجميع أحدث
عملية تشغيل لكل سير عمل مرتبط؛ النتائج الفاشلة لها الأسبقية على النتائج قيد التشغيل، والمعلقة، والملغاة، والناجحة، وغير
المعروفة. إن متطلبات الموافقة على سير العمل ليست موافقة على مراجعة التعليمات البرمجية أو الموافقة على الدمج أو مؤشر
تعارض الدمج.

<a id="inspect-details"></a>

## فحص التفاصيل

حدد صفًا لفتح صفحة تفاصيل Repovio الخاصة به. قم بمراجعة الهوية، والمستودع، والمؤلف، والمتنازل لهم، والتسميات، والمعالم
الرئيسية، وحالة الموفر، والطوابع الزمنية، ووصف Markdown المعقم. يتم عرض سياق سير العمل المرتبط عند توفره. تتم إزالة HTML
المضمن والعلامات غير الآمنة. لا تتم مزامنة التعليقات وردود الفعل والمرفقات واختلافات التعليمات البرمجية. استخدم رابط
الموفر للتعليق أو التعيين أو التصنيف أو الإغلاق أو المراجعة أو الموافقة أو الدمج. لا ينفذ Repovio أيًا من عمليات الكتابة
هذه.

<a id="synchronization-and-failures"></a>

## التزامن والفشل

تقوم خطافات الويب الموقعة بإدراج القراءات الخاصة بالمستودع بعد نافذة اندماج مدتها 15 ثانية؛ المصالحة لمدة 30 دقيقة تغطي
الأحداث الفائتة. يؤدي تحديث المتصفح إلى إعادة تحميل البيانات المخزنة. في حالة غياب السجل، قم بمسح عوامل التصفية، وتحقق
من تمكين المستودع وعضويته، وافحص [مهام المزامنة](/docs/v1.0/guide-jobs). يمكن للاحتفاظ إزالة السجلات القديمة المغلقة.
يمكن أن تشير صفحة التفاصيل التي لا يمكن الوصول إليها إلى إبطال الوصول أو إلى سجل تمت إزالته؛ العودة إلى القائمة. أعد
محاولة فشل الطلب بعد استرداد واجهة برمجة التطبيقات.
