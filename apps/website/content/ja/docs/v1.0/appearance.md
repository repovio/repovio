<a id="color-mode"></a>

## カラーモード

ユーザー メニューのテーマ/外観コントロールを開き、**システム**、**ライト**、または**ダーク**を選択します。システムはブラウザのオペレーティング システムの色の設定に従います。ライトとダークは固定テーマを選択します。ブラウザは設定をローカルに記憶します。別のデバイスは別のモードを使用できます。テーマを変更しても、リポジトリ データ、アカウント ロール、プロバイダ設定は変更されません。

Web サイトには、アプリケーションとは別に、独自のテーマ コントロールとブラウザー設定があります。ドキュメントのスクリーンショットでは、可能な場合は明るい/暗いバリアントが使用されます。 [システム] が選択されているときにデバイスのシステム テーマが変更された場合、インターフェイスはその設定に従います。設定がリロード後に存続しない場合は、ブラウザーのストレージの可用性を確認してください。

<a id="layout-and-keyboard-controls"></a>

## レイアウトとキーボードのコントロール

サイドバーの折りたたみと応答性の高いナビゲーションでは、許可されている同じ目的地が保持されます。ユーザー メニューからキーボード ショートカット ヘルプを開くか、 を押します。
`?`。 `/` 検索を開きます。 `Meta+K`
キーボード ショートカットが適用できる場合、コマンド パレットが開きます。コマンド パレットには、プロバイダー/リポジトリを追加するための許可されたナビゲーションと管理者ショートカットが含まれています。
