<a id="change-a-password"></a>

## パスワードを変更する

ローカル アカウントの場合は、**設定 → 一般 → パスワードの変更**
を開きます。現在のパスワード、12 ～ 256 文字の新しいパスワード、および一致の確認を入力します。一度送信して完了を待ちます。無効な現在のパスワード、短いパスワード、または不一致の確認は、再試行する前に修正する必要があります。

変更が成功すると、現在のブラウザの代替トークンが返され、アカウントの他の既存のセッションが無効になります。他のデバイスは、新しいパスワードを使用して再度サインインする必要があります。これにより変更されるのは Repovio アカウントのみで、プロバイダー PAT、OAuth 資格情報、通知資格情報、または MCP トークン構成は変更されません。

<a id="oidc-and-forgotten-passwords"></a>

## OIDC と忘れたパスワード

OIDC で管理されるアカウントには、ローカル パスワード フォームがありません。そのプロバイダーで ID プロバイダーのパスワードを変更します。 Repovio には、電子メールベースのリセット フローが意図的にありません。デプロイメントオペレーターは、文書化された
[ローカルリカバリコマンド](/docs/v1.0/authentication#reset-a-forgotten-password)
を使用できます。 OIDC アカウントを拒否し、既存のセッションを無効にします。代替パスワードをシェル履歴や問題レポートに決して入れないでください。
