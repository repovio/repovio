> আর্কাইভ সোর্স স্ন্যাপশট। পণ্য লেবেল Repovio ব্যবহার করে। অপরিবর্তিত এই রিলিজের ট্যাগ করা ডিপ্লয়মেন্ট ফাইল থেকে
> কনফিগারেশন শনাক্তকারী এবং কন্টেইনার রেফারেন্স ব্যবহার করুন।

<a id="server-requirements"></a>

## সার্ভারের প্রয়োজনীয়তা

ব্রাউজার পুশ একটি স্থানীয় পরিবহন এবং Apprise ব্যবহার করে না। স্থাপনা অপারেটর তিনটি সেটিংস কনফিগার করে:

```dotenv
WEB_PUSH_VAPID_PUBLIC_KEY=...
WEB_PUSH_VAPID_PRIVATE_KEY=...
WEB_PUSH_VAPID_SUBJECT=mailto:admin@example.com
```

`npx web-push generate-vapid-keys` এর সাথে একটি VAPID কী জোড়া তৈরি করুন। বিষয় হল একটি `mailto:` বা `https:` URI৷
ব্যক্তিগত কী গোপন রাখুন। সম্পূর্ণ কনফিগারেশন ছাড়া, ব্রাউজার পুশ অনুপলব্ধ হিসাবে দেখানো হয়। একটি নিরাপদ ব্রাউজার
প্রসঙ্গ এবং একটি ব্রাউজার সমর্থনকারী পরিষেবা কর্মীদের এবং Push API ব্যবহার করুন৷

<a id="enable-or-disable-this-device"></a>

## এই ডিভাইসটি সক্ষম বা অক্ষম করুন

**এই ডিভাইসে সক্ষম করুন** ব্যবহার করুন এবং অনুরোধ করা হলে ব্রাউজারের বিজ্ঞপ্তির অনুমতি দিন। সদস্যতা বর্তমান ব্যবহারকারী
এবং ব্রাউজারের অন্তর্গত। একজন প্রশাসক একটি ব্রাউজার-পুশ চ্যানেলে প্রাপক ব্যবহারকারীদের নির্বাচন করেন; প্রতিটি প্রাপকের
একটি সক্ষম ডিভাইস প্রয়োজন। ব্রাউজার অনুমতি প্রত্যাখ্যান সাবস্ক্রিপশন বাধা দেয়; সাইটের ব্রাউজার অনুমতি সামঞ্জস্য করুন
এবং ইচ্ছা হলে পুনরায় চেষ্টা করুন। একটি পরীক্ষা পাঠানোর আগে উপলব্ধতা/ডিভাইসের সংখ্যা এবং রিপোর্ট করা ত্রুটিগুলি পরীক্ষা
করুন৷

পুশ অক্ষম করা এই ডিভাইসের সদস্যতা সরিয়ে দেয়, অন্য ডিভাইস নয়। এন্ডপয়েন্ট এবং কীগুলি এনক্রিপ্ট করা হয় এবং অ-গোপন
আঙ্গুলের ছাপ দিয়ে অনুলিপি করা হয়। HTTP 404/410 প্রতিক্রিয়া মেয়াদোত্তীর্ণ সদস্যতা সরিয়ে দেয়। একটি অনুপলব্ধ
ব্রাউজার, অনুপস্থিত সার্ভার কনফিগারেশন, অস্বীকৃত অনুমতি, বা সাবস্ক্রিপশন অনুরোধ ব্যর্থতার জন্য সংশ্লিষ্ট কারণটি ঠিক করা
প্রয়োজন; একা রিফ্রেশিং ব্রাউজার অনুমতি দিতে পারে না। প্রচেষ্টার জন্য [ডেলিভারি ইতিহাস](/docs/v1.0/notification-history)
দেখুন।
