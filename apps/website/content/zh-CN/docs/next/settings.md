## 设置选项卡

从用户菜单中打开**设置**。每个经过身份验证的用户都可以访问**常规**和**MCP**。系统管理员还可以查看**身份验证**和**系统**。侧边栏的管理员分组不会阻止其他登录用户通过用户菜单打开其个人设置。

一般包含 [轮廓](/docs/next/profile)、[阿凡达](/docs/next/avatar)，对于本地帐户，包含
[密码](/docs/next/password)。 OIDC 管理的用户会看到身份管理通知，而不是本地配置文件/密码表单，但仍可以编辑其头像。
[MCP](/docs/next/mcp) 管理个人只读访问令牌。

<a id="related-preferences"></a>

## 相关偏好设置

从应用程序/用户控件中选择 [语言](/docs/next/language) 和 [外貌](/docs/next/appearance)。管理员在各自的选项卡中配置
[OIDC认证](/docs/next/authentication) 和
[系统默认值](/docs/next/settings-system)。缺少的选项卡可能适合您的角色；更改 URL 并不授予授权。仅在检查 API 连接后重试失败的设置请求。
