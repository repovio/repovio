> لهذا الإصدار دون تغيير.

<a id="change-a-password"></a>

## تغيير كلمة المرور

بالنسبة للحساب المحلي، افتح **الإعدادات → عام → تغيير كلمة المرور**. أدخل كلمة المرور الحالية وكلمة المرور الجديدة
المكونة من 12 إلى 256 حرفًا والتأكيد المطابق. أرسل مرة واحدة وانتظر الانتهاء. يجب تصحيح كلمة المرور الحالية غير الصالحة
أو كلمة المرور القصيرة أو التأكيد غير المتطابق قبل إعادة المحاولة.

يؤدي التغيير الناجح إلى إرجاع رمز مميز بديل للمتصفح الحالي وإبطال جلسات الحساب الأخرى الموجودة. يجب على الأجهزة الأخرى
تسجيل الدخول مرة أخرى باستخدام كلمة المرور الجديدة. يؤدي هذا إلى تغيير حساب Repovio فقط، وليس PATs للموفر، أو بيانات
اعتماد OAuth، أو بيانات اعتماد الإشعارات، أو تكوين الرمز المميز MCP.

<a id="oidc-and-forgotten-passwords"></a>

## OIDC وكلمات المرور المنسية

لا تحتوي الحسابات المُدارة بواسطة OIDC على نموذج كلمة مرور محلية. قم بتغيير كلمة مرور موفر الهوية لدى ذلك الموفر.
Repovio ليس لديه تدفق إعادة تعيين قائم على البريد الإلكتروني عمدًا. يمكن لمشغل النشر استخدام
[أمر الاسترداد المحلي](/docs/v1.0/authentication#reset-a-forgotten-password) الموثق؛ فهو يرفض حسابات OIDC ويبطل الجلسات
الحالية. لا تضع أبدًا كلمة مرور بديلة في سجل الصدفة أو في تقرير المشكلة.
