## 設定タブ

ユーザーメニューから**設定**を開きます。認証されたすべてのユーザーは**全般** および**MCP**
にアクセスできます。システム管理者には、**認証**と**システム**も表示されます。サイドバーの管理者グループは、サインインしている他のユーザーがユーザー メニューから個人設定を開くことを妨げません。

一般には [プロフィール](/docs/v2.0/profile)、[アバター](/docs/v2.0/avatar)、ローカル アカウントの場合は
[パスワード](/docs/v2.0/password)
が含まれます。 OIDC で管理されているユーザーには、ローカル プロファイル/パスワード フォームの代わりに ID 管理通知が表示されますが、アバターを編集することはできます。
[MCP](/docs/v2.0/mcp) は、個人の読み取り専用アクセス トークンを管理します。

<a id="related-preferences"></a>

## 関連する設定

[言語](/docs/v2.0/language) および [外観](/docs/v2.0/appearance)
はアプリ/ユーザー コントロールから選択されます。管理者は、それぞれのタブで [OIDC認証](/docs/v2.0/authentication) と
[システムのデフォルト](/docs/v2.0/settings-system)
を構成します。タブが欠落していても、あなたの役割には適している可能性があります。 URL を変更しても承認は付与されません。 API 接続を確認した後でのみ、失敗した設定リクエストを再試行してください。
