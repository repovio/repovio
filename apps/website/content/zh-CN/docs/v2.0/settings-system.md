<a id="administrator-access"></a>

## 管理员权限

只有系统管理员可以打开**设置→系统**。加载显示骨架；加载失败会提供错误并重试，而不是根据丢失的数据推断出可编辑的默认值。在保存更改之前等待设置请求。

<a id="retention-defaults"></a>

## 保留默认值

为工作流运行、问题和拉取请求设置单独的默认保留期。每个值必须介于 1 到 3650 天之间。存储库可以独立覆盖每个相应的值；空存储库覆盖会恢复系统默认值。保留会影响本地存储的历史记录，而不是提供商端的记录。缩短保留时间可能会删除较旧的存储数据，因此请首先检查报告和调查要求。

存储库保留和跟踪控制记录在 [存储库](/docs/v2.0/repositories) 中。丢失的历史行可以反映保留而不是失败的提供程序同步。

<a id="datetime-formatting"></a>

## 日期/时间格式

设置默认日期/时间格式并在保存之前检查其实时预览。区域设置选择仍然控制翻译的界面文本和区域设置敏感的格式。保存一次；成功和验证/API 失败分别报告。更正或 API 恢复后重试。格式化首选项永远不会更改原始提供程序时间戳。
