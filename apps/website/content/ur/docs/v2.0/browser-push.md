## سرور کی ضروریات

براؤزر پش ایک مقامی ٹرانسپورٹ ہے اور Apprise استعمال نہیں کرتا ہے۔ تعیناتی آپریٹر تینوں ترتیبات کو ترتیب دیتا ہے:

```dotenv
WEB_PUSH_VAPID_PUBLIC_KEY=...
WEB_PUSH_VAPID_PRIVATE_KEY=...
WEB_PUSH_VAPID_SUBJECT=mailto:admin@example.com
```

`npx web-push generate-vapid-keys` کے ساتھ VAPID کلید کا جوڑا بنائیں۔ موضوع ایک `mailto:` یا `https:` URI ہے۔ نجی کلید
کو خفیہ رکھیں۔ مکمل کنفیگریشن کے بغیر، براؤزر پش کو غیر دستیاب کے طور پر دکھایا گیا ہے۔ ایک محفوظ براؤزر سیاق و سباق اور
براؤزر کو سپورٹ کرنے والے سروس ورکرز اور پش API کا استعمال کریں۔

<a id="enable-or-disable-this-device"></a>

## اس ڈیوائس کو فعال یا غیر فعال کریں۔

**اس ڈیوائس پر فعال کریں** کا استعمال کریں اور درخواست کرنے پر براؤزر کی اطلاع کی اجازت دیں۔ سبسکرپشن موجودہ صارف اور
براؤزر سے تعلق رکھتی ہے۔ ایک منتظم براؤزر پش چینل میں وصول کنندہ صارفین کا انتخاب کرتا ہے۔ ہر وصول کنندہ کو ایک فعال
ڈیوائس کی ضرورت ہوتی ہے۔ براؤزر کی اجازت سے انکار سبسکرپشن کو روکتا ہے۔ سائٹ کے براؤزر کی اجازت کو ایڈجسٹ کریں اور اگر
چاہیں تو دوبارہ کوشش کریں۔ ٹیسٹ بھیجنے سے پہلے دستیابی/آلہ کی گنتی اور رپورٹ کی گئی غلطیوں کو چیک کریں۔

پش کو غیر فعال کرنے سے اس آلے کی سبسکرپشن ہٹ جاتی ہے، دوسرے آلات سے نہیں۔ اینڈ پوائنٹس اور کیز کو خفیہ اور غیر خفیہ فنگر
پرنٹ کے ساتھ ڈپلیکیٹ کیا جاتا ہے۔ HTTP 404/410 جوابات میعاد ختم ہونے والی سبسکرپشنز کو ہٹا دیتے ہیں۔ ایک غیر دستیاب
براؤزر، غائب سرور کنفیگریشن، اجازت سے انکار، یا سبسکرپشن کی درخواست کی ناکامی کے لیے متعلقہ وجہ کو درست کرنے کی ضرورت
ہے۔ اکیلے ریفریشنگ براؤزر کی اجازت نہیں دے سکتی۔ کوششوں کے لیے [ترسیل کی تاریخ](/docs/v2.0/notification-history) دیکھیں۔
