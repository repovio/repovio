この読み取り専用参照は、選択したアプリケーション リリースから生成されます。検索フィールドを使用してエンドポイントを見つけます。ネストされたフィールドのスキーマ詳細を展開し、必要に応じて完全な OpenAPI
JSON をダウンロードします。

インストールによって提供されるドキュメントについては、[APIアクセス](/docs/v2.0/api-access) を参照してください。
