Repovio হল GitHub অ্যাকশন, GitLab পাইপলাইন, Forgejo অ্যাকশন এবং Gitea অ্যাকশনগুলির জন্য একটি স্ব-হোস্ট করা ড্যাশবোর্ড৷
নির্বাচিত ওয়ার্কফ্লো রান, সমস্যা এবং অনুরোধগুলি ট্র্যাক করুন, বর্তমান ব্যর্থতাগুলি সনাক্ত করুন এবং প্রদানকারী
সংস্থানগুলি পরিবর্তন না করে বিজ্ঞপ্তি পাঠান৷

<a id="one-permission-scoped-overview"></a>

## একটি অনুমতি-স্কোপড ওভারভিউ

- কর্মপ্রবাহের স্বাস্থ্য, সর্বশেষ রান, প্রবণতা, অনুমোদনের সারি এবং মনোযোগের প্রয়োজন এমন কাজ পরিদর্শন করুন।
- সমস্যাগুলি পড়ুন এবং তাদের সম্পর্কিত ওয়ার্কফ্লো ক্রিয়াকলাপের পাশাপাশি অনুরোধগুলি টানুন বা মার্জ করুন৷
- গোপন মান সংরক্ষণ না করে সমর্থিত নিরাপত্তা-সতর্ক মেটাডেটা পর্যালোচনা করুন।
- সংগ্রহস্থল সদস্যপদ, এনক্রিপ্ট করা বিজ্ঞপ্তি গন্তব্য এবং শুধুমাত্র-পঠনযোগ্য প্রদানকারী সংযোগগুলি পরিচালনা করুন৷
- স্থানীয় অ্যাকাউন্ট, ঐচ্ছিক OpenID কানেক্ট এবং ব্যক্তিগত পঠনযোগ্য MCP অ্যাক্সেস টোকেন ব্যবহার করুন।

প্রদানকারী পরিবর্তন, অনুমোদন, পর্যালোচনা এবং কর্মপ্রবাহ পুনঃরান বাহ্যিক কর্ম থেকে যায়. Repovio এর নিজস্ব প্রশাসন
নিয়ন্ত্রণগুলি এর স্থানীয় ট্র্যাকিং এবং বিজ্ঞপ্তিগুলি কনফিগার করে; তারা প্রদানকারীকে লেখার অ্যাক্সেস দেয় না।

[ইনস্টলেশন](/docs/next/installation) দিয়ে শুরু করুন, তারপর [সাইন ইন এবং নেভিগেশন](/docs/next/sign-in) অনুসরণ করুন।
উৎপাদন কার্যক্রমের জন্য, [স্থাপনা এবং ব্যাকআপ](/docs/next/deployment) দেখুন।
