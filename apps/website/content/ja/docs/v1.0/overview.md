> アーカイブされたソース スナップショット。製品ラベルはRepovioを使用します。このリリースのタグ付きデプロイメント ファイルの構成識別子とコンテナー参照を変更せずに使用します。

Repovio は、GitHub アクション、GitLab パイプライン、Forgejo アクション、および Gitea アクション用の自己ホスト型ダッシュボードです。プロバイダーのリソースを変更せずに、選択したワークフローの実行、発行、プル リクエストを追跡し、現在の障害を特定して通知を送信します。

<a id="one-permission-scoped-overview"></a>

## 1 つの権限スコープの概要

- ワークフローの健全性、最新の実行、傾向、承認キュー、注意が必要な作業を検査します。
- 問題を読み取り、関連するワークフロー アクティビティと一緒にリクエストをプルまたはマージします。
- シークレット値を保存せずに、サポートされているセキュリティ アラート メタデータを確認します。
- リポジトリのメンバーシップ、暗号化された通知先、読み取り専用のプロバイダー接続を管理します。
- ローカル アカウント、オプションの OpenID Connect、および個人の読み取り専用 MCP アクセス トークンを使用します。

プロバイダーの変更、承認、レビュー、ワークフローの再実行は外部アクションのままです。 Repovio 独自の管理コントロールにより、ローカル追跡と通知が構成されます。プロバイダーに書き込みアクセスを許可しません。

[インストール](/docs/v1.0/installation) から始めて、[サインインとナビゲーション](/docs/v1.0/sign-in)
に従います。運用操作については、「[導入とバックアップ](/docs/v1.0/deployment)」を参照してください。
