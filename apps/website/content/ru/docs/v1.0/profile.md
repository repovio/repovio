<a id="edit-a-local-profile"></a>

## Редактировать локальный профиль

Откройте **Настройки → Общие**. Локальные пользователи могут обновить необязательные имена/фамилии и свое имя
пользователя для входа. Личные имена используются в качестве предпочтительного отображаемого идентификатора; имя
пользователя остается доступным для однозначной идентификации. Поля имеют максимальную длину 255 символов, имя
пользователя не может быть пустым.

Для изменения имени пользователя требуется текущий пароль. Введите его в форму профиля и выберите «Сохранить». Сами по
себе имена не требуют изменения имени пользователя. Дождитесь запроса; успешное сохранение обновляет текущую учетную
запись. Повторяющееся имя пользователя и неправильный текущий пароль приводят к различным ошибкам проверки. Исправьте
поврежденное поле и повторите попытку.

<a id="identity-managed-accounts"></a>

## Аккаунты, управляемые с помощью личных данных

Пользователи OIDC не могут изменять свое имя пользователя или имена профилей локально. Repovio синхронизирует имена из
проверенных утверждений личности при успешном входе в систему. Измените их у поставщика удостоверений и войдите снова.
Аватар остается доступным для отдельного редактирования в [Настройки аватара](/docs/v1.0/avatar). Если запрос профиля не
удался, повторите попытку после восстановления API; не отправляйте пароли через каналы поддержки.
