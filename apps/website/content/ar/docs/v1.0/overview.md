> لقطة المصدر المؤرشفة. تستخدم ملصقات المنتجات Repovio. استخدم معرفات التكوين ومراجع الحاوية من ملفات النشر ذات العلامات
> لهذا الإصدار دون تغيير.

Repovio عبارة عن لوحة معلومات ذاتية الاستضافة لإجراءات GitHub وخطوط أنابيب GitLab وإجراءات Forgejo وإجراءات Gitea. تتبع
عمليات سير العمل المحددة والمشكلات وطلبات السحب، وحدد حالات الفشل الحالية وأرسل الإشعارات دون تعديل موارد الموفر.

<a id="one-permission-scoped-overview"></a>

## نظرة عامة واحدة على نطاق الإذن

- فحص سلامة سير العمل وأحدث عمليات التشغيل والاتجاهات وقوائم انتظار الموافقة والعمل الذي يحتاج إلى الاهتمام.
- قراءة المشكلات وسحب الطلبات أو دمجها جنبًا إلى جنب مع نشاط سير العمل ذي الصلة.
- مراجعة بيانات تعريف التنبيهات الأمنية المدعومة دون تخزين القيم السرية.
- إدارة عضويات المستودع ووجهات الإشعارات المشفرة واتصالات الموفر للقراءة فقط.
- استخدم الحسابات المحلية وOpenID Connect الاختياري ورموز الوصول الشخصية للقراءة فقط MCP.

تظل تغييرات الموفر والموافقات والمراجعات وعمليات إعادة تشغيل سير العمل بمثابة إجراءات خارجية. تعمل عناصر التحكم الإدارية
الخاصة بـ Repovio على تكوين التتبع والإشعارات المحلية الخاصة بها؛ لا يمنحون الموفر حق الوصول للكتابة.

[النشر والنسخ الاحتياطي](/docs/v1.0/deployment).
