Repovio はウェブサイトの全 13 言語に対応し、既存のイタリア語、オランダ語、ポーランド語、
ポルトガル語の翻訳も引き続き提供します。アプリで選択できるのは、英語、ドイツ語、スペイン語、
フランス語、イタリア語、オランダ語、ポーランド語、ポルトガル語、簡体字中国語、ヒンディー語、
アラビア語、ベンガル語、ブラジルポルトガル語、インドネシア語、ウルドゥー語、ロシア語、日本語の 17 言語です。
ポルトガル語（`pt`）とブラジルポルトガル語（`pt-BR`）は別々の選択肢です。

英語が既定の言語であり、フォールバック先でもあります。保存済みの `repovio-locale` ブラウザー Cookie は、
対応するブラウザー言語の設定より優先されます。未対応の設定は英語にフォールバックします。
言語を変更しても、現在のルートとクエリパラメーターは保持されます。
日付、時刻、数値の表示は選択した言語に従い、設定済みの 24 時間制および ISO 形式の方針も維持されます。

アラビア語とウルドゥー語は右から左のレイアウトを使用し、その他の言語は左から右のレイアウトを使用します。
プロバイダー側で作成された名前、リポジトリ識別子、URL、コードは元の値を保持し、読みやすい方向で表示されます。

<a id="sign-in-controls-and-language-flags"></a>

## ログイン操作と国旗

サインイン画面、最初の管理者のセットアップ画面、サインイン後のユーザーメニューでは、
同じ言語名の現地語表記と装飾用のローカル SVG 国旗を表示します。言語名はアクセシブルなラベルとして維持されます。
長いメニューはスクロールでき、キーボードでも操作できます。
言語のダウンロードが完了するまで、操作元のコントロールは処理中の状態を維持し、繰り返し選択することはできません。
ダウンロードに失敗すると、Repovio は元の言語に戻し、翻訳されたエラーメッセージを表示します。
失敗したアセットのダウンロードを再試行するには、ページを再読み込みしてから、その言語をもう一度選択してください。

公開の認証ページには、システム設定、ライト、ダークを順に切り替えるテーマボタンもあります。
アイコンは現在の設定を示し、ツールチップとアクセシブルな名前は現在の設定と次の操作を説明します。

ロケールと国旗の国コードの対応は次のとおりです。

| ロケール | 国  | ロケール | 国  |
| -------- | --- | -------- | --- |
| `en`     | GB  | `zh-CN`  | CN  |
| `de`     | DE  | `hi`     | IN  |
| `es`     | ES  | `ar`     | SA  |
| `fr`     | FR  | `bn`     | BD  |
| `it`     | IT  | `pt-BR`  | BR  |
| `nl`     | NL  | `id`     | ID  |
| `pl`     | PL  | `ur`     | PK  |
| `pt`     | PT  | `ru`     | RU  |
| `ja`     | JP  |          |     |

`apps/web/public/flags` のアセットは
[flag-icons v7.5.0](https://github.com/lipis/flag-icons/tree/v7.5.0) に由来し、同梱の MIT ライセンスに従います。
外部の画像サービスや翻訳サービスは不要です。

<a id="adding-or-updating-a-locale"></a>

## ロケールの追加または更新

1. `apps/web/i18n/locales/en.json` を、現在の完全なメッセージの参照元として使用してください。
   アクセシブルなラベル、検証メッセージ、空・エラー・読み込み中の状態、パラメーター、
   単数・複数の意味を含め、提供するすべてのメッセージカタログを完全に翻訳します。
2. `apps/web/shared/locales.ts` に、正確なコード、言語タグ、現地語の言語名、カタログファイル、文字方向、
   国旗の国コード、Nuxt UI のロケール識別子を登録します。既存のコードを保持し、`pt` と `pt-BR` を区別してください。
3. `apps/web/app/utils/locales.ts` で、インストール済みの Nuxt UI のロケールエクスポートをマッピングします。
   例として `zh_cn` や `pt_br` があります。
4. ライセンスに従ったローカルの国旗アセットを追加し、帰属表示を保持してください。
   ウェブサイトの実装をアプリにインポートしないでください。
5. カタログの検査とブラウザーのテストシナリオを実行します。
   テストは実際のウェブサイトの言語レジストリとアプリの対応状況を比較し、メッセージの欠落、
   互換性のないパラメーター、不正な構文、UI マッピングの欠落、国旗アセットの欠落を検出すると失敗します。
   英語へのフォールバックは完全な翻訳の代わりにはなりません。製品名や技術的なリテラルは元のままで問題ありません。

固定された Node.js 26.13.0 と pnpm 11.28.9 のツールチェーンを有効にし、ローカルのアプリを起動してから、
次を実行してください。

```sh
corepack pnpm --dir apps/web test
corepack pnpm --dir apps/web lint
corepack pnpm --dir apps/web typecheck
corepack pnpm --dir apps/web exec playwright test tests/e2e/localization.spec.ts \
  tests/e2e/auth-preferences.spec.ts tests/e2e/localization-rtl.spec.ts
```

ライト・ダークテーマと狭い・広い画面のスクリーンショットを確認してください。
特に、右から左の表示、中日韓の文字、インド系文字の表示に注意してください。
現在の `next` ハンドブックの各言語版を一貫して更新し、公開済みのバージョンアーカイブは変更しないでください。
