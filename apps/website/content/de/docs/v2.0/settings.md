<a id="settings-tabs"></a>

## Registerkarten „Einstellungen“.

Öffnen Sie **Einstellungen** im Benutzermenü. Jeder authentifizierte Benutzer kann auf**Allgemein** und**MCP**
zugreifen. Systemadministratoren sehen auch **Authentifizierung** und**System**. Die Administratorgruppierung der
Seitenleiste hindert andere angemeldete Benutzer nicht daran, ihre persönlichen Einstellungen über das Benutzermenü zu
öffnen.

Allgemein enthält [Profil](/docs/v2.0/profile), [Avatar](/docs/v2.0/avatar) und für lokale Konten
[Passwort](/docs/v2.0/password). Von OIDC verwaltete Benutzer sehen anstelle lokaler Profil-/Passwortformulare einen
Hinweis zur Identitätsverwaltung, können ihren Avatar jedoch weiterhin bearbeiten. [MCP](/docs/v2.0/mcp) verwaltet
persönliche Lesezugriffstoken.

<a id="related-preferences"></a>

## Verwandte Einstellungen

[Sprache](/docs/v2.0/language) und [Aussehen](/docs/v2.0/appearance) werden aus den App-/Benutzersteuerelementen
ausgewählt. Administratoren konfigurieren [OIDC-Authentifizierung](/docs/v2.0/authentication) und
[Systemvorgaben](/docs/v2.0/settings-system) in ihren jeweiligen Registerkarten. Ein fehlender Tab kann für Ihre Rolle
richtig sein; Durch das Ändern einer URL wird keine Autorisierung gewährt. Versuchen Sie fehlgeschlagene
Einstellungsanfragen erst erneut, nachdem Sie die API-Konnektivität überprüft haben.
