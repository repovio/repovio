<a id="access-and-channel-list"></a>

## Доступ и список каналов

Откройте **Операции → Уведомления → Каналы**. Каналы представляют собой глобальную конфигурацию Repovio, а не
конфигурацию менеджера, принадлежащего репозиторию. Системные администраторы создают, редактируют, тестируют,
включают/отключают и удаляют каналы. Статус менеджера репозитория не дает права администрирования канала. В таблице
показано имя, тип, метаданные безопасного места назначения, подписанные события, включенное состояние и время
обновления; используйте фильтры типа/включенные, сортировку, элементы управления столбцами и нумерацию страниц.

<a id="create-a-destination"></a>

## Создать пункт назначения

Выберите **Добавить канал**, введите имя, выберите тип и настройте пункт назначения:

- **Электронная почта:** хост/порт SMTP, транспортная безопасность, отправитель, дополнительная проверка подлинности и
  получатели.
- **Gotify:** URL-адрес сервера, токен приложения и приоритет.
- **ntfy:** сервер, тема, дополнительная аутентификация/токен и приоритет.
- **Discord:** назначение веб-перехватчика.
- **Пользовательский URL-адрес Apprise:** поддерживаемый URL-адрес службы Apprise.
- **Push-уведомления браузера:** пользователи-получатели; каждый получатель должен включить
  [их устройство](/docs/v2.0/browser-push).

Настройте [подписки на мероприятия и предварительный просмотр](/docs/v2.0/notification-rules) в том же диалоговом окне.
Сохраните и дождитесь запроса перед закрытием. Ошибки проверки или сохранения оставляют форму доступной для исправления.

<a id="edit-test-and-remove"></a>

## Редактировать, тестировать и удалять

Место назначения шифруется в состоянии покоя. Вы можете сохранить его, но не сможете прочитать обратно. При
редактировании сохраненные учетные данные сохраняются, если не выбран параметр **Заменить целевую конфигурацию**. Тип
канала не может быть изменен; вместо этого создайте новый канал. Перенесенный канал с пометкой**Требуется
переконфигурация** нельзя повторно включить, пока не будет заменен его пункт назначения. Каналы, отправляемые через
браузер, используют пользовательские подписки и отклоняют секрет назначения транспорта.

Используйте действие проверки строки, чтобы отправить реальное уведомление в настроенный пункт назначения; он не
изменяет данные поставщика. Просмотрите результат в [История доставки](/docs/v2.0/notification-history). Отключите
канал, чтобы приостановить доставку, или удалите его, когда он больше не нужен. Удаление выполняется немедленно. Никогда
не вставляйте учетные данные в снимки экрана или отчеты службы поддержки.

Электронная почта, Gotify, ntfy, Discord и пользовательские адресаты используют встроенный в API интерфейс командной
строки Apprise; отдельный сервер Apprise не требуется. Если запрос не выполнен, повторите попытку после восстановления
API. Пустой список означает, что ни один из видимых настроенных каналов не соответствует фильтрам; очистите фильтры или
создайте канал. Сведения о сбое доставки содержат только сообщения об ошибках, из которых удалены конфиденциальные
данные.
