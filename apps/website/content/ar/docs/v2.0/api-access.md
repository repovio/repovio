## وثائق API المثبتة

يقدم كل خادم Repovio API وثائق API التفاعلية الخاصة به في `/docs`. في التنمية المحلية، افتح
`http://localhost:3001/docs`. تستخدم نقاط نهاية REST المسار الأساسي `/api/v1`.

بالنسبة للنشر، استخدم أصل واجهة برمجة التطبيقات (API) الذي يمكن الوصول إليه خارجيًا والمسار الذي تم تكوينه بواسطة الوكيل
العكسي. على سبيل المثال، إذا تم عرض خادم API على `https://repovio.example.com`، فيمكن عرض وثائقه على
`https://repovio.example.com/docs`. لا يقوم تطبيق الويب تلقائيًا بتعيين وكيل لهذا المسار؛ قم بتكوين الوكيل الخاص بك بشكل
صريح إذا كنت تريد الكشف عنه. `/api/v1/docs` ليس مسار التوثيق.

يصف المرجع المثبت التطبيق قيد التشغيل. تستخدم الطلبات المقدمة من هذا المرجع التفاعلي المثيل الخاص بك وتتطلب المصادقة
والأذونات الموثقة لكل عملية. راجع [المصادقة](/docs/v2.0/authentication) لتسجيل الدخول وتكوين الحساب. رموز الوصول MCP
مخصصة لـ [عملاء MCP](/docs/v2.0/mcp)، وليس كرموز حاملة REST عامة.

## مرجع الإصدار الثابت

إن [مرجع واجهة برمجة التطبيقات](/docs/v2.0/api-reference) الموجود على موقع الويب هذا عبارة عن لقطة للقراءة فقط تم
إنشاؤها من مراجعة التطبيق الدقيقة للإصدار المحدد. لا يحتاج إلى تشغيل مثيل Repovio ولا يرسل طلبات API. اختر الإصدار
المطابق للتثبيت الخاص بك؛ تظل صفحة `/docs` المثبتة موثوقة للإصدار الجاري تشغيله.

ابحث حسب الطريقة أو المسار أو الوصف، وافحص المعلمات ومخططات الاستجابة، أو قم بتنزيل OpenAPI JSON الكامل من الصفحة
المرجعية. تحتفظ معرفات المخطط وأوصاف واجهة برمجة التطبيقات بلغة العقد الذي تم إنشاؤه.
