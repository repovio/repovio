Repovio 是用于 GitHub 操作、GitLab 管道、Forgejo 操作和 Gitea 操作的自托管仪表板。跟踪选定的工作流程运行、问题和拉取请求，识别当前故障并发送通知，而无需修改提供程序资源。

<a id="one-permission-scoped-overview"></a>

## 一个权限范围的概述

- 检查工作流程运行状况、最新运行情况、趋势、审批队列和需要关注的工作。
- 阅读问题并拉取或合并请求及其相关的工作流程活动。
- 查看支持的安全警报元数据而不存储秘密值。
- 管理存储库成员资格、加密通知目的地和只读提供程序连接。
- 使用本地帐户、可选的 OpenID Connect 和个人只读 MCP 访问令牌。

提供商变更、批准、审查和工作流程重新运行仍然是外部操作。 Repovio自己的管理控制配置其本地跟踪和通知；他们不授予提供商写访问权限。
