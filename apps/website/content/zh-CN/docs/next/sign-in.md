<a id="local-sign-in"></a>

## 本地登录

打开`/auth/signin`，输入本地用户名和密码，然后选择**登录**。等待身份验证完成。被拒绝的凭据会让您留在表格上；验证用户名并向部署操作员询问
[密码恢复](/docs/next/authentication#reset-a-forgotten-password)。 Repovio没有电子邮件密码重置流程。

新安装会打开
[首次运行设置](/docs/next/setup)。经过身份验证后，导航和结果取决于您的角色和存储库成员身份。仪表板为空并不意味着登录失败。

<a id="openid-connect"></a>

## OpenID 连接

当管理员启用 OIDC 时，请使用其他提供商登录按钮。在身份提供商自己的页面上完成身份验证并让回调完成。被拒绝的组映射、过期的事务或提供者失败会返回错误；开始新的登录尝试。 OIDC 绝不会通过匹配电子邮件来链接现有的本地帐户。

OIDC 登录与提供商 OAuth 连接分开。对Repovio用户进行身份验证；它不连接 GitHub、GitLab、Forgejo 或 Gitea 存储库。身份管理的名称和密码必须在身份提供商处更改。

<a id="sign-out"></a>

## 退出

从用户菜单中选择注销。注销会删除浏览器会话，而不会删除存储库、更改提供程序凭据或修改提供程序资源。在共享设备上，完成后注销。如果 API 会话过期，请在重试失败的操作之前重新登录。启用 OIDC 后，本地密码登录仍然可用。
