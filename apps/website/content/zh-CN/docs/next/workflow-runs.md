## 浏览保留的运行

打开**概述 → 工作流程运行 → 所有运行**。结果仅限于可访问的存储库和保留的历史记录。使用存储库、提供者、状态和持续时间过滤器（持续时间以秒为单位输入）。所有运行都没有文本搜索框；需要注意添加搜索和详细的创建/启动列。对列进行排序、更改可见列并对结果进行分页。如果预期运行缺失，请清除过滤器。

行标识工作流程和存储库、提供程序、规范化状态、提供程序时间戳和提供时的持续时间。排队或未完成的运行可能缺少完成时间或最终持续时间。归一化状态为
`queued`、`running`、`success`、`failed`、`cancelled`、`skipped` 和 `unknown`。必须在提供商处检查未知状态。

<a id="open-a-run"></a>

## 打开运行

使用外部行操作打开提供程序运行及其日志。 Repovio 不提供单独的可编辑运行屏幕、下载提供程序工件或同步完整日志。仅使用您的提供商帐户在提供商处批准、重新运行、取消或发送。对于当前故障，请使用
[需要注意](/docs/next/needs-attention)；对于门，请使用 [等待批准](/docs/next/awaiting-approval)。

<a id="missing-or-stale-history"></a>

## 历史记录缺失或陈旧

空表意味着没有保留的记录与过滤器和您的权限匹配。保留可以删除较旧的运行。检查存储库启用、成员资格、工作流允许/拒绝模式和
[同步任务](/docs/next/guide-jobs)。页面刷新会重新加载存储的数据；它不会绕过持久同步队列。 API 恢复后重试加载错误。
