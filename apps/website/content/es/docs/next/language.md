<a id="application-preference"></a>

## Preferencia de aplicación

Cada usuario que haya iniciado sesión puede seleccionar un idioma en el menú de usuario/control de idioma de la
aplicación. La aplicación admite inglés (`en`), alemán (`de`), español (`es`), francés (`fr`), italiano (`it`), holandés
(`nl`), polaco (`pl`) y portugués (`pt`). El idioma seleccionado afecta los mensajes de la interfaz y el formato de
fecha, hora y número. Los nombres de los repositorios, los nombres de los flujos de trabajo y las descripciones
proporcionados por el proveedor permanecen sin cambios.

El navegador almacena la preferencia en `repovio-locale` para futuras visitas. El inglés es el valor predeterminado y
determinista para los valores no admitidos. Otro navegador/dispositivo tiene sus propias preferencias. Si un cambio no
se puede completar, vuelva a intentarlo después de que se recupere la navegación. Consulte
[Localización](/docs/next/localization) para mantener las traducciones de aplicaciones.

<a id="website-and-handbook"></a>

## Sitio web y manual

El sitio web y el manual ofrecen 13 idiomas independientemente de los ocho idiomas de la interfaz de la aplicación.
Utilice el selector de idioma del sitio web para conservar la versión y la página de la documentación actual mientras
cambia de idioma. El árabe y el urdu utilizan un diseño de derecha a izquierda. Las capturas de pantalla pueden mostrar
la aplicación en inglés incluso cuando se traduce el texto circundante; Los títulos de las imágenes identifican esa
elección. Elegir un idioma de documentación no lo agrega a la aplicación.
