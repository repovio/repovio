> アーカイブされたソース スナップショット。製品ラベルは Repovio に正規化されています。この履歴リリースでは、タグ付けされたデプロイメント ファイルからの構成識別子とコンテナー参照を変更せずに使用します。

Repovio の Web インターフェイスは、英語 (`en`)、ドイツ語 (`de`)、スペイン語 (`es`)、フランス語 (`fr`)、イタリア語 (`it`)、オランダ語 (`nl`)、ポーランド語 (`pl`)、ポルトガル語で出荷されています。 (`pt`)。アプリケーション ヘッダーの言語メニューは、サインインしているすべてのユーザーが利用できます。言語を選択すると、その設定が
`ezrepo-locale` ブラウザーの Cookie に保存され、次回の訪問時に適用されます。

英語が決定的なデフォルトおよびフォールバックです。ブラウザー設定または保存された Cookie がサポートされているロケールを識別しない場合、Repovio は英語を表示します。日付、時刻、数値の書式設定には、選択したロケールが使用されます。

<a id="adding-or-updating-a-locale"></a>

## ロケールの追加または更新

1. 完全なキー参照として `en.json` を使用して、`apps/web/i18n/locales/<locale>.json` を追加または更新します。
2. ロケールコード、ファイル名、ネイティブ表示名を`apps/web/nuxt.config.ts`に登録します。
3. `en.json`
   に存在するすべてのメッセージ キーを保持します。 Web テスト スイートは、出荷されたロケールごとにこのパリティをチェックします。
4. ユーザーに表示される新しいインターフェイス文字列ごとに英語とドイツ語のメッセージを追加し、出荷されたすべてのロケールに対応する翻訳を追加します。
5. `pnpm --filter @repovio/web test`、`pnpm --filter @repovio/web typecheck`、および影響を受ける Playwright テストを実行します。

プロバイダー名、リポジトリ名、ワークフロー名、およびその他のプロバイダーが提供するデータは、Repovio インターフェイスのコピーではないため、変更されません。
