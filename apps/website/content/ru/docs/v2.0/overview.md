Repovio — это автономная панель мониторинга для действий GitHub, конвейеров GitLab, действий Forgejo и действий Gitea.
Отслеживайте выполнение выбранных рабочих процессов, проблемы и запросы на включение, выявляйте текущие сбои и
отправляйте уведомления, не изменяя ресурсы поставщика.

<a id="one-permission-scoped-overview"></a>

## Один обзор на уровне разрешений

- Проверяйте работоспособность рабочего процесса, последние запуски, тенденции, очереди утверждений и работу, требующую
  внимания.
- Читайте проблемы и запросы на извлечение или слияние вместе с соответствующими действиями рабочего процесса.
- Просматривайте поддерживаемые метаданные предупреждений безопасности без сохранения секретных значений.
- Управляйте членством в репозитории, зашифрованными местами назначения уведомлений и соединениями с поставщиками,
  доступными только для чтения.
- Используйте локальные учетные записи, дополнительный OpenID Connect и персональные токены доступа MCP только для
  чтения.

Изменения поставщиков, утверждения, проверки и повторы рабочих процессов остаются внешними действиями. Собственные
средства администрирования Repovio настраивают локальное отслеживание и уведомления; они не предоставляют провайдеру
доступ на запись.

Начните с [установка](/docs/v2.0/installation), затем следуйте [вход и навигация](/docs/v2.0/sign-in). Информацию о
производственных операциях см. в [развертывание и резервное копирование](/docs/v2.0/deployment).
