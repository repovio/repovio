<a id="browse-and-filter"></a>

## Просмотр и фильтрация

Откройте **Обзор → Проблемы**. Списки, сводки, варианты фильтров и подробные сведения используют членство в репозитории.
Поиск по названию или номеру; фильтруйте по поставщику, репозиторию, жизненному циклу, автору, правопреемнику, этапу,
меткам и времени обновления, если это возможно. Обновленные границы дат включают время UTC. Несколько выбранных ярлыков
должны совпадать. Измените сортировку, видимые столбцы и нумерацию страниц с помощью элементов управления таблицей. В
сводных карточках учитываются открытые, недавно обновленные, назначенные и устаревшие проблемы. При первоначальной
синхронизации считываются все открытые и закрытые проблемы, обновленные за предыдущие 90 дней. Несвежесть помогает найти
необслуживаемую открытую работу; это не меняет состояние провайдера.

<a id="inspect-details"></a>

## Проверьте детали

Выберите строку, чтобы открыть страницу сведений о Repovio. Просмотрите личность, репозиторий, автора, правопреемников,
метки, этап, состояние поставщика, временные метки и очищенное описание Markdown. Связанный контекст рабочего процесса
отображается, если он доступен. Встроенный HTML и небезопасная разметка удалены. Комментарии, реакции, вложения и
различия в коде не синхронизируются. Используйте ссылку поставщика, чтобы комментировать, назначать, помечать,
закрывать, просматривать, утверждать или объединять. Repovio не выполняет ни одной из этих операций записи.

<a id="synchronization-and-failures"></a>

## Синхронизация и сбои

Подписанные веб-перехватчики ставят в очередь операции чтения, специфичные для репозитория, после 15-секундного окна
объединения; 30-минутная сверка охватывает пропущенные события. Обновление браузера перезагружает сохраненные данные.
Если запись отсутствует, очистите фильтры, проверьте включение и членство репозитория и проверьте
[Задачи синхронизации](/docs/v1.0/guide-jobs). Хранение может удалить старые закрытые записи. Недоступная страница
сведений может указывать на отозванный доступ или удаленную запись; вернуться к списку. Ошибка повторного запроса после
восстановления API.
