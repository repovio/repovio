## アプリケーションの設定

サインインしているすべてのユーザーは、アプリケーションの言語コントロール/ユーザー メニューから言語を選択できます。このアプリケーションは、英語 (`en`)、ドイツ語 (`de`)、スペイン語 (`es`)、フランス語 (`fr`)、イタリア語 (`it`)、オランダ語 (`nl`)、ポーランド語 (`pl`)、ポルトガル語 (`pt`) をサポートしています。選択した言語は、インターフェイス メッセージと日付、時刻、数値の形式に影響します。プロバイダーが提供するリポジトリ名、ワークフロー名、説明は変更されません。

ブラウザーは、今後のアクセスのために設定を `ezrepo-locale`
に保存します。英語は決定的なデフォルトであり、サポートされていない値のフォールバックです。別のブラウザ/デバイスには独自の設定があります。変更を完了できない場合は、ナビゲーションが回復してから再試行してください。アプリケーションの翻訳の保守については、[ローカリゼーション](/docs/v1.0/localization)
を参照してください。

<a id="website-and-handbook"></a>

## ウェブサイトとハンドブック

Web サイトとハンドブックでは、アプリケーションの 8 つのインターフェイス言語とは別に、13 の言語が提供されています。 Web サイトの言語セレクターを使用して、言語を切り替えるときに現在のドキュメントのバージョンとページを保持します。アラビア語とウルドゥー語は右から左のレイアウトを使用します。周囲のテキストが翻訳されている場合でも、スクリーンショットには英語のアプリケーションが表示されます。画像のキャプションでその選択肢がわかります。ドキュメント言語を選択しても、それはアプリケーションに追加されません。
