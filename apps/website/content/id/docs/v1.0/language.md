## Preferensi aplikasi

Setiap pengguna yang masuk dapat memilih bahasa dari kontrol bahasa aplikasi/menu pengguna. Aplikasi ini mendukung
bahasa Inggris (`en`), Jerman (`de`), Spanyol (`es`), Prancis (`fr`), Italia (`it`), Belanda (`nl`), Polandia (`pl`),
dan Portugis (`pt`). Bahasa yang dipilih memengaruhi pesan antarmuka dan format tanggal, waktu, dan angka. Nama
repositori, nama alur kerja, dan deskripsi yang disediakan penyedia tetap tidak berubah.

Browser menyimpan preferensi di `ezrepo-locale` untuk kunjungan berikutnya. Bahasa Inggris adalah default deterministik
dan pengganti untuk nilai yang tidak didukung. Browser/perangkat lain memiliki preferensinya sendiri. Jika perubahan
tidak dapat diselesaikan, coba lagi setelah navigasi pulih. Lihat [Lokalisasi](/docs/v1.0/localization) untuk memelihara
terjemahan aplikasi.

<a id="website-and-handbook"></a>

## Situs web dan buku pegangan

Situs web dan buku pegangan menawarkan 13 bahasa secara independen dari delapan bahasa antarmuka aplikasi. Gunakan
pemilih bahasa situs web untuk mempertahankan versi dan halaman dokumentasi saat ini saat mengganti bahasa. Bahasa Arab
dan Urdu menggunakan tata letak kanan ke kiri. Tangkapan layar dapat menampilkan aplikasi bahasa Inggris bahkan ketika
teks di sekitarnya diterjemahkan; keterangan gambar mengidentifikasi pilihan itu. Memilih bahasa dokumentasi tidak
menambahkannya ke aplikasi.
